# 전역 설정 내보내기

`~/.claude` 는 git 저장소가 아니라 다른 PC 로 옮길 통로가 없다. 이 스킬이 옮길 가치가 있는
것만 골라 `claude-config/` 에 사본을 만든다. **받는 쪽은 `claude-config-import` 를 쓴다.**

## 실행

```bash
# 무엇이 담기는지 먼저 본다 (파일을 쓰지 않는다)
poetry run python .claude/skills/claude-config-export/export.py --dry-run

# 번들 생성
poetry run python .claude/skills/claude-config-export/export.py
```

`--dry-run` 은 담길 항목을 **하나씩 전부** 출력한다. 수십 개 규모라 눈으로 대조할 수 있고,
담기면 안 되는 것이 섞였는지 그 자리에서 보인다. **번들을 만들기 전에 한 번 본다.**

## 무엇을 담는가

`~/.claude` 의 최상위에서 아래만 담는다. **허용목록 방식이다** — 금지목록으로 하면
Claude Code 가 새 폴더를 만들 때마다 조용히 딸려온다.

| 담는 것 | 왜 |
| --- | --- |
| `CLAUDE.md` · `settings.json` | 하네스의 본체 |
| `skills/` · `commands/` · `rules/` · `hooks/` | 규칙과 자동화 |
| `tools/` · `db/` | 도구 스크립트 (venv 는 제외) |
| `~/.claude.json` 의 `mcpServers` 와 프로젝트별 권한 | **빠뜨리면 받는 쪽에서 MCP 가 통째로 사라진다.** 이 파일은 `~/.claude` 밖에 있어 놓치기 쉽다. 단 **자격증명 값은 가려서** 담는다 (아래 참고) |

## 무엇을 담지 않는가 — 받는 쪽이 "왜 없지"를 되묻지 않게

### 자격증명 (`keys/**` · `*.env` · `*.pem` · `*.key` · `.credentials.json`)

**이 저장소는 PUBLIC 이다.** 한 번 커밋되면 파일을 지워도 git 이력에 남는다.
회사 식별 정보는 걸러내지 않기로 했지만(사용자 결정), 자격증명은 층위가 다르다 —
유출되면 실제 접근권이 넘어간다.

**받는 PC 에서 필요한 자격증명은 그 PC 에서 새로 만든다.** 다만 「새로 만든다」가 무엇을
뜻하는지는 파일마다 갈린다 — 구글시트의 두 파일이 그 예다.

| 파일 | 받는 PC 에서 |
| --- | --- |
| `keys/sheets-mcp-token.json` | 동의화면이 「테스트」 상태라 **7일마다 만료**된다. **재인증하면 생긴다** |
| `keys/sheets-mcp-oauth.json` | Google Cloud Console 에서 받은 **클라이언트 시크릿**이다. **재인증으로는 생기지 않는다** — 그 PC 로 따로 옮기거나 Console 에서 다시 내려받는다 |

지라(atlassian)처럼 브라우저 OAuth 로 인증하는 서버는 토큰이 `.credentials.json` 이나
Keychain 에 있어 애초에 담기지 않는다. 받는 PC 에서 한 번 인증하면 된다.

### MCP 서버의 자격증명 «값» — 파일이 아니라 설정 안에 있다

`~/.claude.json` 의 `mcpServers[*].headers` · `env` 에는 **API 키가 값으로 들어간다.**
이 파일은 `~/.claude` **밖**에 있어 위의 경로 판정을 아예 거치지 않고, 실제로 이 자리에서
Context7 키가 번들에 들어간 적이 있다. 그래서 내보낼 때 **그 값을 센티널로 가린다.**

- 판정은 **허용목록**이다 — `headers`·`env` 의 문자열 값 중 **절대경로가 아닌 것을 전부** 가린다
- **경로는 남긴다.** 그것은 자격증명이 아니라 자격증명이 놓인 곳이고,
  받는 쪽이 그 문자열에서 출처 PC 의 홈을 찾아 자기 경로로 바꾼다
- 이름 패턴(`KEY`·`TOKEN` 이 든 키)으로 고르지 않는다 — 구글시트의 `TOKEN_PATH` 가 걸려
  **살려야 할 경로가 죽고**, 새 서버가 다른 이름을 쓰면 조용히 샌다
- `command`·`args` 는 가리지 않는다. 실행 인자라 가리면 받는 쪽에서 서버가 뜨지 않는다.
  그 자리는 `tests/test_claude_config_bundle.py` 의 **번들 전체 패턴 스캔**이 맡는다

무엇을 가렸는지는 **실행 출력에 나온다**(`--dry-run` 에서도). 허용목록이라 자격증명이 아닌
설정값까지 가릴 수 있으므로 그 목록을 한 번 본다.

받는 쪽은 센티널을 알아보고 **그 PC 에 이미 있던 값을 유지한다.** 없으면 센티널을 남기고
채워야 할 항목으로 알려준다.

### 그 밖에

| 담지 않는 것 | 왜 |
| --- | --- |
| `projects/` · `sessions/` · `history.jsonl` · `file-history/` 등 | 세션 상태와 이력. `projects/` 만 426MB 이고, 다른 PC 의 이력이 섞이면 되돌릴 수 없다 |
| `db/*.jsonl` | 감사 로그. 그 PC 에서만 뜻이 있다 |
| `**/venv/**` | 플랫폼 바이너리. 받는 쪽에서 쓸 수 없고 필요하면 재생성한다 |
| `plugins/**` | 공식 마켓플레이스 사본 6.4MB. `officialMarketplaceAutoInstalled` 가 말하듯 **받는 쪽에서 자동으로 다시 설치**되고, `known_marketplaces.json` 은 절대경로를 담고 있어 옮기면 변환 대상만 는다 |
| `cache/` · `backups/` · `*.bak-*` | 캐시와 자동·수동 백업본 |

## 실행 후

1. **`git diff` 로 무엇이 바뀌었는지 본다.** 매니페스트에 항목별 해시가 있어 변경된 파일이 드러난다
2. **git 은 사용자가 직접 한다.** 이 스킬은 파일만 만든다

## 주의

- **`home/` 은 통째로 지우고 다시 만든다.** 원본에서 지운 파일이 번들에 남으면 받는 쪽이
  이미 없어진 설정을 적용하게 된다. `decisions/` 는 받는 쪽의 결정 누적이라 지우지 않는다
- **저장소에 번들이 없는 것이 정상이다.** 받는 쪽은 적용을 마치면 번들 본체를 지우고
  `decisions/` 만 남긴다 — 사본이 원본과 함께 검색에 걸리기 때문이다. 보낼 때마다
  이 스킬로 새로 만든다
- **담을 것이 0개가 된 폴더는 통째로 사라진다.** `venv` 만 든 폴더가 그렇다 — 허용 목록에
  있어도 `DENY_SEGMENTS` 가 안을 전부 걸러내면 폴더가 없는 것과 같아지고, 받는 쪽에는
  **그 도구를 가리키는 권한 규칙만** 남는다. 실측(2026-09-09)으로 `tools/xlsx/` 가 그랬고,
  같은 `tools/` 의 `msg/`·`pptx/` 는 정상으로 담겼다.
  **이것을 고장으로 읽지 않는다** — 보낼 파일이 애초에 0개였고 권한 규칙이 남아 받는 쪽의
  재생성 신호가 됐다. 설계대로 동작한 것이다
- **0개 폴더를 스캔해 경고하지 않기로 했다** (2026-09-09). 경고는 «보내는 쪽»에 뜨는데
  보내는 쪽은 이미 아는 사람이고, 모르는 것은 받는 쪽이다. 대신 `EXCLUSION_NOTICE` 에
  한 줄을 넣어 **번들 README 와 매니페스트**에 실리게 했다 — 받는 쪽이 읽는 자리다
- **정작 뚫린 곳은 「스크립트는 갔는데 그 인터프리터를 가리키는 권한 규칙이 없는」 경우다.**
  받는 쪽의 탐지 기제가 `Bash(/...)` 규칙의 절대경로라서, 규칙이 없으면 그 venv 는 아예
  탐지에 걸리지 않는다. 실측(2026-09-09)으로 `tools/pptx/venv` 가 그랬고 — 규칙이 `xlsx`
  것뿐이라 받는 쪽이 **「mac 이 venv 하나를 공용으로 쓴다」는 틀린 가설**을 세웠다.
  실제로는 venv 가 둘이고 패키지가 겹치지 않는다.
  **새 venv 도구를 만들면 권한 규칙을 함께 넣는다**
- 담기면 안 되는 항목이 번들에 들어가면 **스크립트가 스스로 중단한다.** 같은 판정을
  `tests/test_claude_config_bundle.py` 가 다시 검사한다 — 두 층 모두 `export.py` 의
  **같은 함수**를 쓴다. 판정을 두 벌로 만들면 한쪽이 담아도 된다고 한 파일을 다른 쪽이 거부한다
