# 검증 산출물 정리

`storage/results/` 는 실행할 때마다 폴더가 쌓인다. **결과 문서가 근거로 인용하는 폴더를 지우면
문서에 대조할 수 없는 숫자만 남는다** — 실제로 그 상태의 문서가 8개 쌓인 적이 있다.

**산출물이 사는 자리가 둘이다** — 새 산출물은 `검증`·`매매`·`실측` 계층 폴더 아래에,
그 규약 이전의 산출물은 루트 직하에 있다. 판정과 삭제는 `utils/result_citations.py` 가 내는
**이름 → 경로 대응**을 쓰므로 둘을 함께 본다. 같은 이름이 두 계층에 있으면 **함께** 지운다 —
인용은 이름 단위라 판정이 둘에 같이 걸린다.

무엇이 인용됐는지의 판정은 `src/verify_lab/utils/result_citations.py` 하나가 소유하고,
품질 검증과 이 스킬이 **같은 함수**를 쓴다. 판정을 여기서 다시 만들지 않는다.

## 1. 조준부터 확인한다

**정리 도구는 인용이 정확한 만큼만 안전하다.** 아직 폴더를 겨누지 않은 문서가 있으면
그 근거가 「정리 대상」에 섞여 들어온다.

`docs/research/` 와 `docs/strategy/` 의 각 문서 머리말에서 **근거 산출물이 무엇을 가리키는지**
확인한다. 아래 셋 중 하나면 **조준이 안 된 것**이다.

| 조준 안 됨 | 왜 위험한가 |
| --- | --- |
| 「최신 `*_option_expiry` 폴더」 같은 **패턴** | 재실행이 새 폴더를 만들면 **본문과 값이 다른 폴더**를 가리키게 된다 |
| 「2026-09-05 21:59 실행」 같은 **실행 시각 문장** | 어느 폴더인지 기계가 알 수 없어 정리 대상으로 올라온다 |
| `<실행시각>_usdkrw_grid/` 같은 **자리표시자** | 실행 위치 설명이지 근거가 아니다 |

**완료 기준**: 두 폴더의 모든 문서가 근거 자리에 **폴더명** 또는 **묘비 표기**를 갖는다.
하나라도 조준이 안 됐으면 **먼저 조준하고** 2번으로 간다.

> **묘비 표기**란 산출물이 사라졌다는 사실을 남기는 것이다. 인용과 **같은 줄**에
> `없음`·`삭제`·`제거` 중 하나를 적으면 실재를 요구하지 않는다.
> 없어진 산출물은 이렇게 적어야 문서에 남길 수 있다.

## 2. 목록을 낸다

```bash
poetry run python scripts/maintenance/clean_results.py
```

「지킨다」와 「정리 대상」 두 표가 나온다.

**완료 기준**: `문서가 인용했는데 없는 폴더가 있습니다` 경고가 **없다.**
경고가 나오면 1번의 조준이 덜 끝났거나 누군가 인용 폴더를 이미 지운 것이므로,
정리를 멈추고 그 폴더부터 되살리거나 묘비로 표기한다.

## 3. 사용자에게 보이고 승인받는다

**목록을 보이지 않고 지우지 않는다.** 정리 대상 전체를 폴더명·용량·git 상태와 함께 제시한다.

**되돌릴 수 있는지가 git 추적 여부로 갈리므로 함께 알린다.**

| git 상태 | 지우면 |
| --- | --- |
| **추적중** | git 이력에 남아 **되살릴 수 있다** |
| **미추적** | **되돌릴 수 없다** — 이 저장소에만 있던 마지막 사본이다 |

**미추적 쪽이 위험하다.** 목록에 미추적이 섞여 있으면 그 사실을 눈에 띄게 알린다.

**완료 기준**: 사용자가 목록을 보고 삭제를 승인했다.

## 4. 지운다

```bash
poetry run python scripts/maintenance/clean_results.py --delete
```

추적 여부와 관계없이 지운다. **삭제는 파일 조작일 뿐이고**, 추적 중이던 폴더는
`git status` 에 삭제로 잡힌다 — **그것을 이력에 기록하는 커밋은 사용자가 한다**
(`.claude/rules/session-bootstrap.md` §7).

**완료 기준**: 정리 대상이 0개가 됐고, 추적분이 있었으면 커밋이 필요하다고 사용자에게 알렸다.

## 5. 검증한다

```bash
poetry run python validate_project.py
```

**완료 기준**: `failed=0`. `tests/test_result_citations.py` 가 인용 폴더의 실재를 검사하므로,
실수로 인용 폴더를 지웠다면 여기서 실패한다.

## 지우기 전에 알아 둘 것

- **`git rm` 은 디스크만 줄이고 `.git` 은 줄이지 않는다.** 한 번 커밋된 바이트는 이력에 남으므로,
  저장소 크기 관리의 수단은 **애초에 커밋 범위를 좁게 잡는 것** 하나다
- **재실행 산출물을 무조건 커밋하지 않는다.** 문서가 근거로 삼는 실행만 올린다
- **`meta.json` 은 정리 대상이 아니다.** git 제외 파일이며 최근 5개만 순환 저장한다
