# reference 폴더는 읽기 전용이다

지금 열고 있는 파일은 **이전 프로젝트에서 옮겨온 참고용 원본**이다. verify-lab의 코드가 아니다.

## 절대 하지 않을 것

1. **수정하지 않는다.** 원본 그대로 보존한다
2. **import하지 않는다.** 이 폴더는 `verify_lab` 패키지가 아니며, 옛 프로젝트의 모듈
   (`krx_sprint.*`·`qbt.*`)을 참조하고 있어 그대로는 동작하지 않는다
3. **실행하지 않는다**
4. **복사해 붙이지 않는다.** verify-lab에 맞지 않는 전제(국내 개별종목 패널, 포트폴리오 엔진,
   매매 규칙)가 따라 들어온다

## 할 것

**읽고 이해한 뒤 `src/verify_lab/`에 새로 작성한다.** 이 폴더의 값어치는 코드 자체가 아니라
"이미 한 번 검증된 접근 방식"이다.

- 이 폴더는 품질 검사(Ruff·PyRight·pytest) 대상에서 제외돼 있다. 린트 오류가 보여도 고치지 않는다
- 문서 안의 링크와 파일 경로는 옛 프로젝트 기준이라 열리지 않는다. **깨져 있어도 정상이다**
- 각 파일을 언제 봐야 하는지는 [reference/README.md](../../reference/README.md)에 정리돼 있다

## 대응하는 구현이 끝나면

verify-lab 쪽 구현이 완성되면 해당 참고 파일은 역할이 끝난다. Phase가 끝날 때 정리해도 되며,
지운다고 프로젝트가 깨지지 않는다. 지울 때는 [docs/INDEX.md](../../docs/INDEX.md) 등록도 함께 지운다.
