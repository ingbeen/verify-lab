# docs/context 는 사용자 소유 문서다

지금 열고 있는 파일은 **사용자의 현재 투자 상태를 나타내는 가장 중요한 문서**이며,
이 프로젝트가 시작된 이유가 담겨 있다.

## 수정하지 않는다

- 사용자가 직접 갱신하는 문서다. **AI가 임의로 고치지 않는다**
- 오탈자·깨진 링크를 발견해도 고치지 말고 **언급만** 한다.
  본문의 파일 경로 링크는 옛 프로젝트 기준이라 열리지 않는 것이 정상이다
- 사용자가 명시적으로 갱신을 요청한 경우에만 수정한다

## 읽을 때 붙잡아야 할 것

| 문서 | 이 프로젝트에 주는 것 |
| --- | --- |
| `RESEARCH_q2_2xs_qqq_correlation.md` | **출발점.** 운용 포트폴리오의 낮은 QQQ 상관(0.708)은 자산 분산이 아니라 하락장에서 주식을 비우는 타이밍 신호에서 나왔다. verify-lab은 "QQQ와 다르게 움직이는 매매법을 찾자"의 후속이다 |
| `RESEARCH_qqq_late_entry.md` | **현재 보유 판정.** 이번 사이클은 미진입, 다음 정식 시그널 대기 |

따라서 검증 결과를 해석할 때는 "통계적으로 유의한가"에 더해
**"이 신호는 QQQ와 다르게 움직이는가, 아니면 QQQ가 흔들릴 때 같이 흔들리는가"** 를 함께 답한다.
맥락 없이 숫자만 맞는 보고는 미완성이다.

**다만 이것은 부가 질문이며 탈락 사유가 아니다.** QQQ와 같이 움직여도 통계적 우위가 있으면
유효한 발견이고 부수적 매매법으로 남긴다. 두 과제의 관계는 루트 `CLAUDE.md`
"이 프로젝트의 과제는 둘이다" 가 SoT다.

## 데이터 기준일에 주의

두 문서 모두 **데이터 기준일 2026-07-24에 고정**된 값이다.
"현재 트레이드 적용" 같은 절의 수치는 시간이 지나면 낡는다. 최신 상태로 단정해 인용하지 않는다.

폴더 안내는 [docs/context/README.md](../../docs/context/README.md)에 있다.
