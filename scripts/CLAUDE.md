# CLI 스크립트 계층 가이드

> CRITICAL: CLI 계층 작업 전에 이 문서를 반드시 읽어야 합니다.
> 프로젝트 전반의 공통 규칙은 [루트 CLAUDE.md](../CLAUDE.md),
> 패키지 아키텍처는 [src/verify_lab/CLAUDE.md](../src/verify_lab/CLAUDE.md)를 참고하세요.

## 폴더 목적

`scripts/`는 사용자 인터페이스를 제공하며, 비즈니스 로직(`src/verify_lab/`)을 호출하고
실행 결과를 전달합니다.

**계층 원칙: 도메인 로직 구현 금지, 오직 인터페이스 제공만 담당.**

| 폴더 | 역할 | 실행 주체 |
| --- | --- | --- |
| `data/` | 데이터 수집·품질 점검 | AI 모델 직접 실행 가능 (외부 서버 요청 — 불필요한 재수집 금지) |
| `run_<매매법>.py` | **측정과 체결을 한 번에** 실행 | AI 모델 직접 실행 가능 |

실행 규칙과 **재수집이 기존 결과를 바꾼다는 점**은 루트 [CLAUDE.md](../CLAUDE.md)
"스크립트 실행 규칙"이 SoT입니다.

## 핵심 책임

1. **사용자 인터페이스** — 명령행 인자 파싱, 입력 검증, 실행 옵션 해석
2. **실행 환경 설정** — 로거 초기화, 로그 레벨 설정
3. **비즈니스 로직 호출** — 도메인 모듈 선택, 파라미터 전달, 결과 수령
4. **결과 표시** — 성공/실패 메시지, 요약 통계, `TableLogger` 기반 표 출력
5. **메타데이터 관리** — 결과 파일 생성 시 `meta_manager.save_metadata(타입, 메타)` 호출.
   **타입은 매매법당 하나**입니다 — 실행이 하나이므로 측정·체결로 가르면 같은 실행이 두 줄로 남습니다.
   ISO 8601 타임스탬프(KST), 실행 파라미터, 핵심 통계를 자동 기록하며 최근 N개만 순환 저장합니다.
   **신규 메타 타입은 스크립트 구현 시 정의하고 이 문서의 목록에 추가합니다**
6. **예외 처리** — `@cli_exception_handler` 데코레이터 사용

## 표준 구조

### 필수 구성 요소

- **임포트 순서**: 표준 라이브러리 → 도메인 모듈 → 유틸리티 → 상수
- **로거**: 모듈 레벨에서 생성 (예외 처리 데코레이터가 자동 감지)
- **main 함수**: 데코레이터 적용, 종료 코드 반환
- **진입점 보호**: `if __name__ == "__main__":`

### 실행 흐름

1. 로거 초기화
2. 명령행 인자 파싱
3. 데이터 로딩
4. 비즈니스 로직 호출
5. 결과 표시
6. 메타데이터 저장 (결과 파일 생성 시)
7. 성공 코드 반환

## 코딩 규칙

### 예외 처리

- `main()`에 `@cli_exception_handler` 적용. **try-except 블록 불필요**
- 데코레이터가 예외 캐치, ERROR 로그 기록(스택 트레이스 포함), 종료 코드 1 반환을 자동 수행
- **예외 전파**: 비즈니스 로직에서 발생한 예외를 그대로 전파합니다. 변환하거나 숨기지 않습니다

### 명령행 인자

**이 프로젝트는 인자를 적극적으로 사용합니다.** 같은 검증을 파라미터만 바꿔 여러 번 돌리는 것이
검증의 본질이기 때문입니다. 다만 아래를 지킵니다.

- **기본값을 항상 둡니다.** 인자 없이 실행해도 스펙에 확정된 기본 설정으로 돌아가야 합니다
- 인자는 **대조 실행을 위한 선택지**여야 합니다 (예: 순위 컷 5/10/20, 집계 시작 연도).
  "성과가 좋아지는 값을 찾는 연속 노브"로 쓰지 않습니다 — 그것은 과최적화입니다
- 검증 설계에 확정된 값(측정 구간, 베이스라인 반복 횟수 등)은 인자가 아니라 상수입니다.
  상수 배치 규칙은 [src/verify_lab/CLAUDE.md](../src/verify_lab/CLAUDE.md) "상수 관리"를 따릅니다

### 산출물 저장

- 저장 경로는 `common_constants.py` 상수를 씁니다. **하드코딩 금지**
- 산출물은 `storage/results/<등급>/<한글 이름>/`에 저장합니다. **등급은 `tracks.py` 가 정하고 매매법당 한 폴더이고
  재실행이 그 자리를 덮습니다** — 표기의 SoT 는 [src/verify_lab/CLAUDE.md](../src/verify_lab/CLAUDE.md) 데이터 저장 규칙입니다
- 🔴 **좁혀 돌린 실행이 전체 실행을 덮습니다.** `--ticker QQQ` 처럼 대상을 줄이면 그 결과가 같은
  자리에 쓰여 **8대상 표가 1대상 표가 되고 예외는 나지 않습니다.** 무엇을 돌렸는지는
  `summary.json` 의 `datasets`·`rule` 이 남기고, **기본값으로 다시 돌리면 복원됩니다.**
  결과 문서에 쓸 수치를 낼 때는 **인자 없이** 돌린 것인지 먼저 확인합니다
- CSV 저장 시 반올림 규칙은 [.claude/rules/python.md](../.claude/rules/python.md)를 따릅니다
- **신호일 전체 목록 CSV를 반드시 남깁니다.** 사용자가 차트로 직접 대조하기 위한 원자료입니다
- **모든 CSV 컬럼 헤더는 한글입니다.** 저장 직전에 `COL_* → DISPLAY_*` 로 바꿔서 내보냅니다
  (규칙의 SoT는 [src/verify_lab/CLAUDE.md](../src/verify_lab/CLAUDE.md) 「내부/출력 분리」).
  사용자가 직접 여는 파일이므로 영문 토큰이 그대로 나가면 안 됩니다.
  용어는 [.claude/rules/docs.md](../.claude/rules/docs.md) 의 표준을 따릅니다 (승률 → 오른 비율 등)
- **가격 기준 축을 만들지 않습니다.** 원본가 하나로 재므로 `price_basis` 같은 컬럼이 필요 없습니다
  (루트 [CLAUDE.md](../CLAUDE.md) 측정의 원칙 14)

## 제약사항

| 항목 | 규칙 |
| --- | --- |
| 비즈니스 로직 | CLI 계층에 도메인 로직 포함 금지. 호출만 담당 |
| **실행 요약** | **조립하지 않는다.** runner 가 낸 것을 `save_run_summary(directory, outputs.summary)` 로 그대로 넘긴다 |
| **산출물 파일 이름** | **정의하지 않는다.** 그 검증의 `constants.py` 의 `OUTPUT_FILES` 를 돌며 저장한다 |
| 에러 로깅 | **CLI 계층만 ERROR 레벨 사용.** 비즈니스 로직은 예외만 발생 |
| 종료 코드 | 성공 0, 실패 1 필수 (데코레이터가 자동 처리) |
| 사용자 메시지 | 한글, 명확하고 구체적, 액션 가능한 정보 포함 |

### 요약과 파일 이름을 CLI 가 갖지 않는 이유

둘 다 **여기 두면 반드시 갈라지고, 갈라져도 예외가 나지 않습니다.**

- **요약을 조립하면** 그 검증만 다른 모양을 냅니다 — 배수 검증 둘이 리터럴 키로 조립해
  그 둘만 `row_counts` 가 별칭이었고, `full_period` 는 **저장은 되는데 행 수가 요약에서
  통째로 빠져** 있었습니다. 나열부는 표가 늘 때 조용히 빠지는 자리입니다
- **파일 이름을 CLI 가 들면** 요약의 키와 실제 파일을 잇는 것이 사람의 기억이 됩니다 —
  `run_usdkrw_equivalence.py` 가 `[EQUIVALENCE_FILENAME, counts['equivalence']]` 로
  손수 짝지었고, 한쪽만 고치면 화면 표가 엉뚱한 숫자를 보여줍니다

> 🔴 **`scripts/` 는 거의 테스트 대상이 아닙니다.** 이 저장소의 테스트는 `src` 모듈에 붙으므로
> CLI 가 깨져도 타입 검사와 계약 테스트를 통과합니다 — **실제로 실행해야만 드러납니다.**
> CLI 를 고쳤으면 그 스크립트를 한 번 돌려 보고 넘깁니다.
>
> **예외는 둘뿐이고 «소스 모양»과 «`--help` 렌더링»만 봅니다** — `tests/test_layer_contracts.py` 의
> `TestRunSummaryOwnership`(요약을 CLI 가 조립하지 않는지)과 `TestCliHelpRenders`(`run_*.py` 의
> `--help` 가 실제로 그려지는지). **동작은 여전히 아무도 보지 않습니다** — 인자 배선을 뒤집어도
> 전 검사가 통과하고, 그 신호는 `storage/results/` 의 git diff 뿐입니다.
