# scripts 폴더 가이드

`scripts/`는 CLI 진입점만 둡니다. **비즈니스 로직은 `src/verify_lab/`에 두고 여기서는 호출만 합니다.**

## 폴더 구성

| 폴더 | 역할 | 실행 주체 |
| --- | --- | --- |
| `data/` | 데이터 수집·품질 점검 | **사용자만** (외부 서버 요청) |
| `studies/` | 검증 실행 | AI 모델 직접 실행 가능 |

실행 주체가 다른 이유와 상세 규칙은 루트 [CLAUDE.md](../CLAUDE.md) "스크립트 실행 규칙"을 따릅니다.

## 스크립트 작성 규칙

- 진입점은 `main()` 함수와 `if __name__ == "__main__":` 블록
- 인자 파싱은 `argparse`. 기본값을 항상 두어 인자 없이도 실행되게 합니다
- 로직을 스크립트에 직접 쓰지 않습니다. `src/verify_lab/`의 함수를 호출합니다
  — 테스트가 붙지 않는 코드가 늘어나기 때문입니다
- 결과 출력은 `utils/formatting.py`의 표 출력 도구를 씁니다
- 예외 처리는 CLI 계층에서만 하고, ERROR 로그도 여기서만 남깁니다

## 산출물 저장

- 저장 경로는 `src/verify_lab/common_constants.py`의 상수를 씁니다. 스크립트에 경로를 하드코딩하지 않습니다
- 검증 산출물은 실행할 때마다 덮어쓰지 말고 **실행 시각으로 구분되는 폴더**에 저장합니다.
  같은 검증을 파라미터만 바꿔 여러 번 돌리는 것이 전제이기 때문입니다
- CSV 저장 시 반올림 규칙은 [.claude/rules/python.md](../.claude/rules/python.md)를 따릅니다

## 실행 명령어 등록

새 스크립트를 만들면 **[docs/COMMANDS.md](../docs/COMMANDS.md)에 반드시 추가**합니다.
CLI 옵션이 바뀔 때도 함께 갱신합니다.
