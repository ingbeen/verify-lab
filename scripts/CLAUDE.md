# CLI 스크립트 계층 가이드

> CRITICAL: CLI 계층 작업 전에 이 문서를 반드시 읽어야 합니다.
> 프로젝트 전반의 공통 규칙은 [루트 CLAUDE.md](../CLAUDE.md),
> 패키지 아키텍처는 [src/verify_lab/CLAUDE.md](../src/verify_lab/CLAUDE.md)를 참고하세요.

## 폴더 목적

`scripts/`는 사용자 인터페이스를 제공하며, 비즈니스 로직(`src/verify_lab/`)을 호출하고
실행 결과를 전달합니다.

**계층 원칙: 도메인 로직 구현 금지, 오직 인터페이스 제공만 담당.**

| 폴더 | 역할 | 실행 주체 |
| --- | --- | --- |
| `data/` | 데이터 수집·품질 점검 | AI 모델 직접 실행 가능 (외부 서버 요청 — 불필요한 재수집 금지) |
| `studies/` | 검증 실행 | AI 모델 직접 실행 가능 |
| `strategy/` | 매매 규칙 실행 | AI 모델 직접 실행 가능 |

실행 규칙과 **재수집이 기존 결과를 바꾼다는 점**은 루트 [CLAUDE.md](../CLAUDE.md)
"스크립트 실행 규칙"이 SoT입니다.

## 핵심 책임

1. **사용자 인터페이스** — 명령행 인자 파싱, 입력 검증, 실행 옵션 해석
2. **실행 환경 설정** — 로거 초기화, 로그 레벨 설정
3. **비즈니스 로직 호출** — 도메인 모듈 선택, 파라미터 전달, 결과 수령
4. **결과 표시** — 성공/실패 메시지, 요약 통계, `TableLogger` 기반 표 출력
5. **메타데이터 관리** — 결과 파일 생성 시 `meta_manager.save_metadata(타입, 메타)` 호출.
   ISO 8601 타임스탬프(KST), 실행 파라미터, 핵심 통계를 자동 기록하며 최근 N개만 순환 저장합니다.
   **신규 메타 타입은 스크립트 구현 시 정의하고 이 문서의 목록에 추가합니다**
6. **예외 처리** — `@cli_exception_handler` 데코레이터 사용

## 표준 구조

### 필수 구성 요소

- **임포트 순서**: 표준 라이브러리 → 도메인 모듈 → 유틸리티 → 상수
- **로거**: 모듈 레벨에서 생성 (예외 처리 데코레이터가 자동 감지)
- **main 함수**: 데코레이터 적용, 종료 코드 반환
- **진입점 보호**: `if __name__ == "__main__":`

### 실행 흐름

1. 로거 초기화
2. 명령행 인자 파싱
3. 데이터 로딩
4. 비즈니스 로직 호출
5. 결과 표시
6. 메타데이터 저장 (결과 파일 생성 시)
7. 성공 코드 반환

## 코딩 규칙

### 예외 처리

- `main()`에 `@cli_exception_handler` 적용. **try-except 블록 불필요**
- 데코레이터가 예외 캐치, ERROR 로그 기록(스택 트레이스 포함), 종료 코드 1 반환을 자동 수행
- **예외 전파**: 비즈니스 로직에서 발생한 예외를 그대로 전파합니다. 변환하거나 숨기지 않습니다

### 명령행 인자

**이 프로젝트는 인자를 적극적으로 사용합니다.** 같은 검증을 파라미터만 바꿔 여러 번 돌리는 것이
검증의 본질이기 때문입니다. 다만 아래를 지킵니다.

- **기본값을 항상 둡니다.** 인자 없이 실행해도 스펙에 확정된 기본 설정으로 돌아가야 합니다
- 인자는 **대조 실행을 위한 선택지**여야 합니다 (예: 순위 컷 5/10/20, 집계 시작 연도).
  "성과가 좋아지는 값을 찾는 연속 노브"로 쓰지 않습니다 — 그것은 과최적화입니다
- 검증 설계에 확정된 값(측정 구간, 베이스라인 반복 횟수 등)은 인자가 아니라 상수입니다.
  상수 배치 규칙은 [src/verify_lab/CLAUDE.md](../src/verify_lab/CLAUDE.md) "상수 관리"를 따릅니다

### 산출물 저장

- 저장 경로는 `common_constants.py` 상수를 씁니다. **하드코딩 금지**
- 검증 산출물은 덮어쓰지 않고 `storage/results/<실행시각>_<검증명>/`에 저장합니다
- CSV 저장 시 반올림 규칙은 [.claude/rules/python.md](../.claude/rules/python.md)를 따릅니다
- **신호일 전체 목록 CSV를 반드시 남깁니다.** 사용자가 차트로 직접 대조하기 위한 원자료입니다

## 제약사항

| 항목 | 규칙 |
| --- | --- |
| 비즈니스 로직 | CLI 계층에 도메인 로직 포함 금지. 호출만 담당 |
| 에러 로깅 | **CLI 계층만 ERROR 레벨 사용.** 비즈니스 로직은 예외만 발생 |
| 종료 코드 | 성공 0, 실패 1 필수 (데코레이터가 자동 처리) |
| 사용자 메시지 | 한글, 명확하고 구체적, 액션 가능한 정보 포함 |
