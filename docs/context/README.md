# context — 현재 운용 상태와 이 프로젝트가 시작된 이유

이 폴더의 두 문서는 **사용자의 현재 투자 상태를 나타내는 가장 중요한 문서**입니다.
verify-lab이 왜 존재하는지, 검증 결과를 어떤 판단에 쓸 것인지가 여기서 나옵니다.

**작업 전에 반드시 읽으세요.** 검증 설계를 논의하거나 결과를 해석할 때 이 맥락을 모르면
"통계적으로 유의한가"에만 답하고 **"그래서 내 포트폴리오에 무슨 의미인가"** 를 놓칩니다.

## 두 문서

### RESEARCH_q2_2xs_qqq_correlation.md — 이 프로젝트가 시작된 이유

운용 중인 포트폴리오(Q-2-2XS)와 QQQ의 상관 구조를 분해한 연구입니다.

핵심 결론: 이 포트폴리오의 낮은 상관(0.708)은 **자산 분산이 아니라 하락장에서 주식을 비우는
타이밍 신호**에서 나왔습니다. 평상시(전체의 77.8%)에는 QQQ와 0.971로 거의 같은 자산이고,
주식을 비운 15.6% 구간에서만 연결이 끊깁니다.

> **verify-lab은 이 연구의 후속입니다.** "QQQ와 다르게 움직이는 매매법을 찾자"가 출발점이며,
> 12장 "후속 연구 방향"에 적힌 두 갈래(연동 단절 구간 확대 / 보유 중 상관 자체 저감) 중
> 어느 쪽도 아직 검증되지 않았습니다.

검증 결과를 해석할 때 함께 물어야 할 질문: **이 신호는 QQQ와 다르게 움직이는가, 아니면
QQQ가 흔들릴 때 같이 흔들리는가.**

### RESEARCH_qqq_late_entry.md — 현재 보유 판정

`buffer_zone_qqq` 전략의 진행 중 트레이드에 뒤늦게 합류할지에 대한 판정입니다.

핵심 결론: **이번 사이클에는 진입하지 않고 다음 정식 매수 시그널을 기다립니다.**
9장에 현재 트레이드 상태(진입일, 지나간 기회, 다음 기회 발동 조건)가 있습니다.

> 데이터 기준일이 **2026-07-24**로 고정된 문서입니다. 9장(현재 트레이드 적용)의 수치는
> 시간이 지나면 낡습니다. 7~8장(기회별 성과표·통계)은 해당 트레이드가 끝나기 전까지 유효합니다.

## 읽을 때 주의

  verify-lab에 존재하지 않아 열리지 않습니다. 내용을 읽는 용도입니다
- 원본을 **수정하지 않습니다.** 사용자가 갱신하는 문서입니다
- 두 문서는 `docs/research/CLAUDE.md`가 규정한 결과 문서 형식의 **실물 예시**이기도 합니다.
  새 검증 결과를 쓸 때 구성(결론 요약표 → 근거 → 해석 → 기각된 가설 → 한계 → 재현 방법)을 참고하세요
