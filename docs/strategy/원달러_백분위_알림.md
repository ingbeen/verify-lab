## 1. 확정 규칙

### 1.1 달러 매수 — 시간 기반 무조건 분할

```
배정액을 정한다        ← 사용자가 정한다. 총자산 비중이 아니라 금액이다
그 금액을 N개월에 걸쳐 매월 정액으로 산다
환율을 보지 않는다     ← 알림이 무엇을 말하든 예정대로 집행한다
```

| 항목 | 값 |
| --- | --- |
| 방식 | 월 1회 정액 매수 |
| 조건 | **없음.** 환율·백분위·추세 어느 것도 보지 않는다 |
| 분할 기간 N | **미확정** — 3~6개월을 권한다 (근거는 §3 결정 D2) |
| 배정액 | **미확정** — 사용자가 정한다 |

**조건을 걸지 않는 것이 이 규칙의 핵심입니다.** 「떨어지면 산다」로 바꾸는 순간
조건이 안 올 때 영영 못 사고, 그것이 이 트랙에서 세 번 확인된 실패입니다
([../research/달러_조달_방식.md](../research/달러_조달_방식.md) §10.2).

### 1.2 백분위 알림 — 정보 전용

**네 창의 값을 나란히 냅니다. 하나만 내지 않습니다.**

| 항목 | 정의 |
| --- | --- |
| 창 | **최근 1년 · 3년 · 5년 · 10년** |
| **백분위** | 그 창에서 **지금보다 쌌던 날의 비율(%)**. `(과거 종가 < 현재 종가).mean() × 100` |
| **평균대비** | `현재 ÷ 그 창의 평균 − 1`. 음수면 평균보다 싸다 |
| **범위** | 그 창의 최저 ~ 최고 종가 |
| 가격 계열 | **원달러 정규장 종가** (`storage/series/USDKRW_CLOSE.csv`) |
| 백분위 소수점 | **정수로 반올림** |
| 평균·범위 소수점 | 원 단위 정수 |
| 평균대비 소수점 | 소수 1자리 |

두 지표가 **같은 방향**을 가리킵니다 — **백분위가 낮을수록, 평균대비가 음수일수록 지금이 쌉니다.**
"상위 / 하위"를 섞어 쓰지 않습니다. 읽는 방향이 뒤집혀 혼란을 만듭니다.

**판정 어휘를 붙이지 않습니다.** 「매우 쌈」·「비싼 편」 같은 말은 예측력이 없는 지표를
행동 지시로 바꿉니다 (§3 결정 D4).

**말미의 주의 문구를 빼지 않습니다.** 이 지표에 예측력이 없다는 것이 측정 결과이고

### 1.4 아직 구현하지 않은 것

| 항목 | 상태 |
| --- | --- |
| 매수 내역 입력 · 평균단가 표시 | **미구현.** 지금은 달러 보유가 0이라 입력할 내역이 없다 |
| 알림 발송 수단·주기 | **미확정** |
| 밴드 리밸런싱 | **보류** — 달러가 쌓인 뒤 판단한다 (§3 결정 D6) |

기록해 둘 것은 **(날짜 · 실제 나간 원화 · 실제 받은 달러)** 세 가지입니다.
환율은 그 둘에서 역산되므로 따로 적지 않아도 되고, 이렇게 적으면 **환전 스프레드가
자동으로 반영된 실효 단가**가 나옵니다.

## 2. 이 규칙의 성적

**이 규칙에는 수익률 성적이 없습니다.** 목표가 수익이 아니라 가용성이기 때문입니다.
대신 측정된 것은 **"매매 규칙을 얹어도 이득이 없다"** 는 사실이며, 그것이 이 규칙이
아무것도 얹지 않는 이유입니다.

근거는 [../research/달러_조달_방식.md](../research/달러_조달_방식.md) 이고,
**그 문서가 개정돼도 이 문서가 자립하도록** 핵심만 아래에 복사합니다.

### 2.1 백분위에 예측력이 없다 (research §9)

"백분위가 낮을 때 산 것이 유리했는가" — 그 후 12개월 평균 환율과 비교했습니다.

| 백분위 구간 | **최근 2년 창** 유리 비율 | **최근 3년 창** 유리 비율 |
| --- | ---: | ---: |
| 0 ~ 20 (쌈) | 50.2% | 53.4% |
| 20 ~ 40 | **36.1%** | 51.8% |
| 40 ~ 60 | 48.6% | **39.3%** |
| 60 ~ 80 | 53.6% | 50.4% |
| 80 ~ 100 (비쌈) | **57.9%** | **54.4%** |

표본 각 8,369일. **판정: 신호 없음.** 근거 넷입니다.

1. 단조롭지 않다 — 두 창 모두 **비쌀 때(80~100)가 가장 유리**하게 나온다
2. **창을 1년 늘렸더니 최악 구간이 20~40 에서 40~60 으로 이동**한다
3. 유리 비율이 전부 **36~58%** 로 동전던지기 범위다
4. forward 12개월 구간이 겹쳐 **표본이 독립이 아니다** — 실질 독립 사건 약 36개

### 2.2 분할 진입도 유리하지 않았다 (research §8)

| 분할 기간 | 표본 | 분할이 더 싸게 산 비율 | 평균 차이 | 중앙값 |
| --- | ---: | ---: | ---: | ---: |
| 6개월 | 1,048 | 46.8% | **+0.38%** | +0.24% |
| 12개월 | 1,025 | 47.2% | **+0.83%** | +0.37% |
| 24개월 | 976 | 48.1% | **+1.74%** | +0.45% |

양수는 분할이 **더 비싸게 샀다**는 뜻입니다. 원달러가 2005-01-03 1,038원에서
2026-08-26 1,384.80원으로 **+33.4%** 올랐고, 오르는 자산은 늦게 살수록 비쌉니다.

**그래도 분할하는 이유는 성적이 아니라 감내 가능성입니다.** 차이가 표본 노이즈 안에 있으므로
어느 쪽도 데이터로 정당화되지 않고, 그렇다면 견딜 수 있는 쪽을 고르는 것이 맞습니다.

### 2.3 밴드 리밸런싱은 지금 환율에서 발동하지 않는다 (research §7)

| 시작 | 시작 환율 | 매도 | 매수 | 그냥 보유 대비 |
| --- | ---: | ---: | ---: | ---: |
| 2005-01-03 | 1,038원 | 9 | 5 | +3,336,644 |
| 2022-09-28 | 1,440원 | **0** | **0** | **0** |
| 2024-08-21 | 1,337원 | 1 | 0 | +593,829 |

배정액 1억, ±10%, **이자와 거래비용 제외**. 현재 1,384.80원에서 상단은 **1,523원**인데
역대 최고가가 **1,570원**입니다. 사상 최고 부근까지 가야 걸립니다.

| **D5** | 백분위 = **지금보다 쌌던 날의 비율** | "이보다 비쌌던 날의 비율" | 낮을수록 싸다가 평균대비(음수면 쌈)와 **같은 방향**이 된다. 반대로 정의하면 두 지표가 서로 반대를 가리킨다 |

| **D8** | 기록은 **(날짜 · 나간 원화 · 받은 달러)** | (날짜 · 원화 · 환율) | 실제 나간 원화와 실제 받은 달러로 적으면 **환전 스프레드가 자동으로 실효 단가에 들어간다.** 고시 환율을 적으면 비용이 빠진다 |

### 파라미터를 옮기면 결과가 흔들리는가

**흔들립니다. 그리고 그것이 이 규칙에 매매를 얹지 않는 근거입니다.**

- 백분위 창을 2년 → 3년으로 바꾸면 **최악 구간이 이동**합니다 (§2.1)
- 밴드 폭을 ±10% → ±3% 로 좁히면 2022-09-28 시작에서 발동이 **0회 → 9회**로 바뀝니다

흔들림은 **"그 값이 좋다"가 아니라 "표본이 그 지점을 특정할 만큼 크지 않다"** 는 신호이고,
그래서 어느 폭도 채택하지 않았습니다.

## 4. 한계

- **이 규칙에는 성적이 없습니다.** 아직 한 번도 집행하지 않았고, 목표가 수익이 아니라
  가용성이라 수익률로 평가할 대상이 아닙니다. §2 는 "얹지 않기로 한 것들"의 측정입니다.
- **분할 기간과 배정액이 미확정입니다.** 둘 다 사용자 결정이며, 정해지기 전에는
  이 문서의 §1.1 이 완성되지 않습니다.
- **인출(달러를 주식으로 옮기는 것)의 성적을 재지 않았습니다.** 처리 규칙은 정했지만
  — 인출 비율만큼 보유 달러와 배정액을 함께 줄인다 — 그 규칙 아래에서의 성적은 재지 않았습니다.
- **미국주식 폭락과 원달러 급등의 관계를 재지 않았습니다.** D1 의 전제인데
  이 저장소에서 측정된 적이 없습니다.
- **단일 통화·단일 경로입니다.** 원달러의 21.6년 또는 36.5년 한 경로이며,
  §2.2 의 "오르는 자산" 전제가 뒤집히면 결론도 뒤집힙니다.
- **거래비용과 세금이 §2 의 수치에 반영되지 않았습니다.** 조달 단가 비교라 양쪽에
  같은 비용이 붙지만 절대 수준은 실제보다 낙관적입니다.
- **알림 값은 데이터가 갱신될 때마다 바뀝니다.** §5 는 2026-08-26 시점의 사진입니다.
