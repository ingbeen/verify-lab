- [x] 목표 1: 체결 격자를 **진입 시점 × 청산 시점**으로 바꾼다 — 둘 다 「가장 최근 반감기 뒤 몇 개월」이고 0 ~ 45개월 3개월 간격(16 × 16 = 256칸)이다. 청산 시점이 진입 시점보다 뒤면 같은 사이클에서, 같거나 앞이면 **다음 반감기 뒤** 그 시점에 판다
- [x] 목표 2: 손절선 격자 **11종**(무손절 + 진입가 대비 −5 ~ −50%, 5%p 간격)을 기본 실행에서 전부 낸다 — 좁히지 않는다
- [x] 목표 3: **하드포크 몫**(BCH · BTG)을 체결마다 잰다 — 포크 코인을 첫 시세일 종가에 팔아 BTC 를 더 산 것으로 본다. 성적과 1차 판정에는 넣지 않는다
- [x] 목표 4: `성적표.csv` · `거래내역.csv` 를 새 격자로 **바꾸고**, 1단계 · 2단계 측정 표는 **바이트 그대로** 둔다
- [x] 목표 5: 결과를 `결과.md` 에, 결정 · 탈락안 · 실측을 `설계.md` 에 남긴다 — 사용자가 규칙(칸 · 손절선 · 분할)을 고를 재료다

- **규칙을 고르지 않는다.** `규칙.md` 는 사용자가 이 격자를 보고 칸 · 손절선 · 분할 창을 고른 뒤 따로 만든다(`.claude/rules/trading.md` 「값 하나를 확정 — `규칙.md` 에서만」). 등급은 검증 그대로다
- 분할매수 코드를 만들지 않는다 — 균등 시간 분할은 같은 청산 칸들의 평균과 수식상 같아 문서에서 읽는다(사용자 결정 2026-09-30)
- 1단계 측정 격자(진입 × 보유 48칸) · 기준선 · 2단계 지표 측정을 바꾸지 않는다
- 3단계 격자에 **기준선을 새로 만들지 않는다**(아래 제안 P4)
- 비용 · 세금 · 환율 · 레버리지 · 「아래」 방향을 넣지 않는다
- 하드포크 몫을 체결 수익률 · 성적표 · 1차 판정에 더하지 않는다 — 원본가 한 기준(측정의 원칙 14)이고 배당락과 같이 **따로 잰다**
- 다음 반감기(2028) 추정 날짜를 넣지 않는다(결정 ⑫)
- 공유 계층(`execution` · `measure` · `report`)을 바꾸지 않는다
- `docs/DEFERRED_FINDINGS.md` 의 항목 중 **이 계획이 다시 쓰는 줄 밖의 것**은 고치지 않는다
