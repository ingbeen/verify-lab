## 3) 배경/맥락(Context)

### 현재 문제점 / 동기

**2026-09-21 에 대상 칸을 120 → 3 으로 좁혔으나 손절선 격자 20종은 그대로 두었다.** 그 결과
성적표가 **3칸 × 손절선 20종 × 시기 5구간 = 300행**이고, 사용자가 실제로 보는 것은
`손절선(%) = -5.0` 인 15행뿐이다. 사용자가 「−5% 만 하기로 했는데 왜 다른 것도 리스트업되느냐」고
물었고, **「실제 투자하는 것만 남긴다」는 같은 결정을 손절선 축에도 적용하기로 정했다**
(2026-09-21 사용자 확정).

**격자를 남겨 둔 근거는 셋이었고, 둘은 다른 수단으로 대체된다.**

| 원래 근거 | 좁힌 뒤 어떻게 되나 |
| --- | --- |
| 「격자를 내는 것은 고르는 것이 아니다」 (측정의 원칙 1) | **값을 재선정하지 않으므로 고르는 행위가 없다.** 칸을 3개로 좁힐 때와 같은 구조다 |
| 재수집 뒤 재선정용 대조축 | **`EXPIRY_STOP_LEVELS` 상수와 CLI 인자를 남겨** 필요할 때 격자를 낸다 (목표 3) |
| 무손절 행이 「손절이 무엇을 막았는가」를 보여 준다 | **문서에 수치로 남긴다** (목표 2) — 사용자가 제안한 대체 수단 |

**세 번째가 이 계획서의 핵심이다.** `규칙.md` §2.4·§2.5·§3.1 이 이미 대조를 담고 있으나
**전부 좁히기 «전» 기준**이다 — §2.5 는 KODEX 200 을 포함한 **5칸 합계**, §3.1 격자는
**후보 24칸·체결 612건**. **지금 3칸 기준의 무손절 대조는 어느 문서에도 없다.**

그리고 3칸 기준에서는 **결론이 반대로 나온다.** 5칸에서는 손절이 합계를 −8.61%p 깎았는데,
그 손실이 전부 KODEX 200 9월의 것이었고 **그 칸이 빠졌으므로** 3칸에서는 손절이 오히려
합계를 늘린다. 이 사실이 문서에 없으면 §2.5 만 읽고 「손절이 수익을 깎는다」로 잘못 읽는다.

**🔴 조용히 깨지는 자리가 하나 있다.** `scripts/run_option_expiry.py` 의 `_print_candidates`
(199~229행)가 `손절선(%) == 무손절` 행만 필터해 화면에 낸다. 무손절 행이 사라지면
**언제나 「1차 게이트를 넘은 칸이 없습니다」만 찍히고 예외는 나지 않는다.**
