## 7) 리스크(Risks)

- **외부 API 의 동작이 조용히 바뀐다** — Bitstamp 의 빈 응답 · Coin Metrics 의 페이지 방향처럼 **에러 없이 결과만 달라지는** 모양이 이미 둘 실측됐다. 완화: 첫 페이지가 비면 예외, 빠진 날 수를 매 수집마다 결과로 내고 화면에 보인다, 요청 인자를 기본값에 맡기지 않는다
- **Coin Metrics 무료 데이터의 축소** — 2025-10-28 커뮤니티 데이터 축소 공지가 있었다(사전조사 §4.2). 완화: 받은 파일이 저장소에 남는다(git). 끊기면 보완 계열 후보(사전조사 §2 질문 1)를 다시 고른다
- **공유 로더 변경의 회귀**(C = 가) — 완화: 키워드 전용 · 기존 상수가 기본값 · 전체 테스트로 확인. 기존 산출물은 재실행하지 않는다
