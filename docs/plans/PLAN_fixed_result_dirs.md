## 2) 비목표(Non-Goals)

- **측정·매매 로직을 바꾸지 않는다.** 이 작업으로 달라지는 수치는 없다. 바뀌는 것은 산출물이 놓이는 «자리»뿐이다
- **시세를 재수집하지 않는다.** 기간이 늘면 신호 수와 성적이 달라져 이 작업의 「재실행해도 같다」가 검증되지 않는다
- **문서의 수치를 새 산출물에 맞춰 갈아 적지 않는다.** 문서의 값은 **그때의 측정 기록**이고, 재실행하지 않은 값을 바꾸면 문서가 거짓말을 한다(`.claude/rules/docs.md` 「수치를 적을 때는 데이터 기간을 함께 적는다」). 어긋남의 방어는 머리말의 데이터 기간 표기 하나이며, 재검증은 매매법별 별건이다
- **`docs/research/` 「관련 파일」 표의 «코드» 묘비는 남긴다.** 「측정 코드가 제거돼 재실행할 수 없다」는 **지워지지 않는 사실**이라 산출물 묘비와 성격이 다르다. 이번에 지우는 것은 **산출물 폴더가 사라졌다**는 문장뿐이다
- **`storage/results/` 를 git 에서 빼지 않는다.** 인용이 사라져도 diff 가 「재실행이 숫자를 바꿨는가」를 알려주는 유일한 신호로 남는다
- **실행 스크립트의 CLI 인자를 바꾸지 않는다.** 좁혀 돌린 실행이 전체 실행을 덮는 것은 「폴더 하나」의 대가로 받아들인다 (아래 Risks)
- **실측 프로브(`scripts/data/check_*.py`)를 재실행하지 않는다.** 외부 서버에 요청을 보내고, 그 사이 늘어난 데이터 때문에 문서에 기록된 실측값과 어긋난 결과가 나온다. 실측 결과의 요약은 이미 `docs/spec/` 의 「데이터 실측 기록」에 있다
