## 3) 배경/맥락(Context)

### 현재 문제점 / 동기

G4-1 로 지표 계층이 섰지만 **비교 대상이 없다.** 지금 "그래서 매매할 가치가 있나"에 답하는 것은
`risk_free_return_rate` 하나뿐이고(세후 CD91 복리 66.32% 대 전략 78.49%), 그것은
스펙 §3.13 이 적었듯 **§13.3 벤치마크의 자리를 임시로 대신한 값**이다.

사양서 §13.3 이 요구하는 것은 세 개이며 목적이 각각 다르다.

| 벤치마크 | 확인 목적 | 이 매매법에서 무엇을 답하나 |
| --- | --- | --- |
| **B&H + 달러 RP** | 매매의 가치 | 첫날 사서 들고만 있었어도 됐나 |
| **분할매수 후 보유** | **익절 로직의 순수 기여** | **§13.3 의 판정** — 못 이기면 익절 로직을 제거하는 것이 맞다 |
| **원화 파킹 100%** | 리스크 대비 정당성 | 환율 위험을 진 대가가 있었나 |

§18 의 결과 해석 지침도 봐야 할 셋 중 **두 번째로 「그리드가 분할매수 후 보유를 이기는가」**를
꼽았다. 지금은 그 질문에 답할 수단이 없다.

#### 착수 전 실측 — 기준선이 그대로 재현된다 (2026-08-26)

기본 설정 환전 2005~ 를 다시 돌려 스펙 §3.13 과 대조했다.

| 항목 | §3.13 | 재실행 |
| --- | --- | --- |
| 총수익률 | +78.49% | **+78.49%** |
| MDD | −8.10% | **−8.10%** |
| Sharpe / Sortino | 0.122 / 0.182 | **0.122 / 0.182** |
| 회전 전체 / 슬롯당 | 29.22 / 1.00회/년 | **29.22 / 1.00회/년** |
| rf 를 그대로 굴렸다면 | +66.32% | **+66.32%** |

**실행 시간은 5,340 거래일에 2.7초**(데이터 로딩 포함)다. 「분할매수 후 보유」가 엔진을 한 번 더
돌리므로 대략 5초가 되며, G5 의 축별 25회에서도 부담이 되지 않는다 — **매 실행에 병기해도 된다**는
근거가 이 값이다.

#### 착수 전에 사용자가 승인한 것 (2026-08-26)

| 물음 | 확정 | 탈락안 |
| --- | --- | --- |
| B&H 의 첫날 매수 비용 | **슬리피지를 뺀 경로 고유 비용만** (환전 0.08% · ETF 0.015%) | 스프레드+슬리피지 0.18% / 비용 0 |
| ETF 실행에서 B&H 가 사는 것 | **실행 중인 경로를 따라간다** | 언제나 환전 B&H |
| 벤치마크를 내는 시점 | **매 실행이 3종을 자동 병기** | `--benchmark` 인자로 분리 실행 |
| 「원화 파킹 100%」의 금리 | **실수령 파킹 금리** `max(CD91 − 0.30%p, 0.50%)`, 15.4% 원천징수 | rf 와 같은 세후 CD91 원지표 |

**B&H 비용의 근거**: 슬리피지는 사양서 §6.6 의 「15:20 돌파 판정과 종가의 차이」를 흡수한 값인데
B&H 의 첫날 매수에는 **돌파 판정이 없다.** 결정 C60 이 같은 이유로 월말 RP 이자 환전에서
슬리피지를 뺐으므로 그 논리를 그대로 잇는다. 크기는 1억 기준 **10만원**(편도 0.10%)이며
방향은 벤치마크에 유리해 그리드 판정에 보수적이다.

**경로를 따라가는 근거**: 결정 C68·C69 가 「세금과 보유 이자율을 경로가 답한다」로 구조를 이미
만들어 뒀다. 벤치마크가 같은 `ExecutionPath` 를 쓰면 **코드에 경로 분기가 생기지 않고**,
§17.3 의 「환전 ≈ 261240」 기대를 B&H 수준에서도 확인할 수 있다.

**파킹 금리의 근거**: rf(결정 C87)는 CD91 **원지표** 세후라 하한도 상품 스프레드도 없고,
파킹 금리는 하한 0.50% 가 걸리는 306일(5.7%)에 **rf 보다 높아지기도 한다.** 두 값이 다르므로
이름을 나눈다 — rf 는 「무위험 수익률」, 벤치마크는 「원화 파킹 100%」다.

#### 이번 조각에서 새로 갈리는 자리

- **이자·월말 판정이 두 곳에서 구현될 위험이 있다.** 엔진의 `_interest_days` 와 월말 판정을
  벤치마크가 다시 쓰면 **두 곳이 조용히 갈라진다** (`src/verify_lab/CLAUDE.md` 「판정식 단일화」).
  → 두 헬퍼를 엔진에서 **공개 이름으로 올려 벤치마크가 같은 것을 부른다**
- **「분할매수 후 보유」는 현금이 빨리 소진된다.** 팔지 않으므로 슬롯이 쌓이기만 하고,
  자금 소진율·최장 보유기간·MDD 가 그리드와 크게 갈릴 것이다 — **그 차이가 곧 익절 로직의 기여**다
- **ETF 의 B&H 는 끝까지 미청산이라 차익 15.4% 가 붙지 않는다** (결정 C8). 환전 경로도 비과세라
  같은 방향이지만, ETF 쪽은 **원래 물어야 할 세금이 유예된 것**이라 편향이 남는다 — 한계에 적는다

| **엔진에 인자를 넣으면서 전략 결과가 달라진다** | 새 인자의 기본값이 기존 동작이고, **종료 총자산 4종을 회귀 대조군**으로 고정한다. 분기는 매도 계획 한 곳뿐이다 |

| **ETF B&H 가 미청산이라 차익 과세를 안 문다** | 결정 C8 의 편향이 그대로 재현된다. **한계에 적는다** — 숨기지 않는 것이 완화다 |
