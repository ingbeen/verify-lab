## 6) 단계별 계획(Phases)

### Phase 0 — 계약을 테스트로 먼저 고정(레드)

**작업 내용**:

- [ ] **크로스체크 계약**: 같은 UTC 날짜의 두 소스 종가를 비교한다. 허용폭 · 걸린 날의 처리는 미결 2 의 결정을 따른다. **걸린 날은 목록으로 남기고 건수를 보고한다** (표본 보존 절대 원칙). 초기 로드와 최신 수신이 **같은 함수**를 부른다 — 두 벌이면 판정이 갈라진다(절대 원칙 5)
- [ ] **보완 이어붙이기 계약**: 주 계열이 없는 날만 보완 계열로 채우고 **행마다 출처를 남긴다** — 출처 없이 섞으면 「원래 값이 없던 날」과 「채운 날」이 구별되지 않는다(`src/verify_lab/CLAUDE.md` 「단일 값 시계열 계층 계약」의 이월 금지와 같은 이유). 2015-01-06 ~ 08 은 미결 5 를 따른다
- [ ] **「최신 미확정 봉」 계약**: 24시간 시장이라 오늘 봉은 늘 미완성이다 — 저장하지 않고 제외 건수를 반환한다(원시 시세 저장 규칙)
- [ ] **반감기 상수 계약**: 블록 높이 210,000 × k 와 블록 시각(UTC)을 상수로 둔다 — 데이터로 유도하면 2024 가 하루 어긋난다(`설계.md` §6.6). 출처는 블록 탐색기로 확정해 `설계.md` 에 적는다
- [ ] **반감기 기준 시점 계약**: 「반감기 + e개월」의 기준은 블록 시각이고, 진입은 그 시각 이후에 닫히는 첫 일봉 종가다. 개월은 **달력 개월**로 더하고 거래일 위치로 세지 않는다(BTC 1년 365봉 대 주식 약 252봉). 말일 넘침은 그 달 말일로 당긴다. 주식 시장 대상(과제 B 의 QQQ 창)은 휴장이면 그 날짜 이후 첫 거래일로 미룬다 — 2016-07-09 · 2024-04-20 이 토요일이다
- [ ] **달력 연도 위치 계약**: 연도 % 4 로 반감기해 · + 1 · + 2 · + 3 을 붙인다. 네 반감기가 모두 % 4 == 0 인 해에 있었다는 사실을 테스트가 단언한다
- [ ] **look-ahead 감시**: 뒤를 잘라낸 입력의 결과가 전체 입력의 결과와 겹치는 범위에서 같다 — 이벤트 정의 · 지표(특히 MVRV-Z 의 표준편차, 미결 12)에 모두 건다
