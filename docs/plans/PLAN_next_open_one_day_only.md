## 3) 배경/맥락(Context)

### 현재 문제점 / 동기

사용자 요청: `signals.csv` 에서 `익일시가 1주`·`1개월`·`3개월`·`6개월`·`1년` 컬럼을 제외한다.
확인 결과 적용 범위를 **산출물 4개 전부**로, `익일시가 1일` 은 **유지**로 확정했다 (2026-08-20).

**익일시가 장기 구간은 종가 기준과 사실상 같은 값을 한 번 더 적는다.** 두 기준은 출구가 같고
입구만 다르므로 개별 신호일에서

```
익일시가 h = (1 + 종가 h) × Close[D] / Open[D+1] − 1
```

이고, 갭 배수 `Close[D]/Open[D+1]` 는 **구간과 무관한 상수**다. 즉 신호일 하나에 대해
`종가 6칸 + 익일시가 1일` 만 있으면 지우는 5칸이 그대로 복원된다. 그런데 현재는 신호일마다
12칸을 적고 있어 `signals.csv` 가 24컬럼(식별 6 + 신호일 6 + 수익률 12)이고, 대조할 때
읽어야 할 칸이 실제 정보량의 두 배다.

**다만 집계 계층에서는 복원이 성립하지 않는다.** 평균·중앙값·승률은 개별 값을 복원한 뒤
다시 집계해야 나오므로, `statistics.csv` 의 익일시가 장기 행은 **되돌릴 수 없는 손실**이다.
이 대가를 알고 내린 결정이며 스펙 결정표에 그대로 적는다.
