## 3) 배경/맥락(Context)

### 현재 문제점 / 동기

재현 결과(2026-10-06 서브에이전트 다섯이 스크래치 사본에서 변형 실행 — 저장소 무변경 확인):

- **T1** — `window_open` 의 신고가 기준에서 `leg.start_months` 대신 1 을 읽게 해도 반감기 테스트 223건 통과. 실제 입력에 넣으면 포지션 315/3,060 · 회차 45/792 가 에러 없이 바뀐다. 픽스처 신고가 창이 전부 1(실제 `SPLIT_BUY_START_MONTHS_HIGH` 의 첫 값)이라서다. 모듈 설명의 「다른 회차 수는 신고가 창 테스트가 본다」도 낡았다(달력 분할 픽스처가 2 · 3회를 쓴다)
- **T2** — 원문의 `trailing_rank` 변형 셋(전 기간 순위 · ±1년 창 · `shift(-1)`)은 `TestTrailingRank` 가 이미 잡는다. 구멍은 `split_grid` 가 순위 · 신고가를 잇는 자리다 — `ranks = trailing_rank(...).shift(-1)` 과 `new_high_flags(closes).shift(-1, fill_value=False)` 가 둘 다 223건 통과하고, 실제 입력에서 포지션 1,566/3,060 이 바뀐다. **자르기 대조만으로는 `shift(-1)` 이 자른 끝 하루에서만 드러난다** — 체결일을 손으로 박아 고정해야 한다
- **T3** — 원문의 예(체결을 다음날 시가로)는 기존 테스트가 잡는다. 같은 결함 모양은 다른 한 줄 — `trading.py` 칸 선택에서 진입 · 청산 개월을 맞바꿈 — 이 199건 통과하고, 격자기준선과 성적표를 맞대면 평균이 120/120칸 다르다
- **T4** — 가드를 `halving.day.day == 31` 로 바꿔도 러너 테스트 59건 통과. 2012-01-01 ~ 2047-12-31 13,149일 중 등식이 멈추는 477일 가운데 29 · 30일 225일을 놓친다(예: 2016-05-30 · 2016-11-29 로 옮긴 반감기)
- **T5** — `periods._verdict` 에 `if mean_value / RATE_TO_PERCENT < 0.02: return "제외"` 를 넣어도 screening · periods · 계약 테스트 114건 통과. 소유자 검사(`TestSingleOwner`)가 동음이의어라 값 「제외」를 일부러 보지 않는다. 적중률 하한을 다시 들이는 변경이 이 모양이다
- **C1** — 전부 NaT 인 datetime 블록이 하나라도 섞인 `pd.concat` 은 경고를 낸다(numpy 2.5.2 · pandas 2.3.3, 스크래치 재현). 날짜 열을 빼고 이은 뒤 배열로 붙이거나 `DatetimeIndex.append` 로 이으면 경고가 없다(같은 스크래치). 실제 실행 경로는 경고 0건이고 짧은 합성 입력 테스트 하나만 걸린다
- **C2** — `monthExtent` 가 `bottom_months` 를 읽게 바꾸면 ① 매수 띠가 −2.694 ~ 32 로 그려지고 차트 테스트가 전부 통과한다(헤드리스 캡처로만 드러남)
- **C3** — 데이터 끝을 과거로 돌려 지금 코드를 그대로 돌리면, 과거의 같은 국면 셋(다음 반감기 2016 · 2020 · 2024)에서 매도 점이 선 끝 밖에 놓인 날이 41 · 151 · 109일, 화면 밖으로 잘린 날이 5 · 0 · 0일이다. 다음 반감기(2027-11 ~ 2028-03 추정) 뒤 2024 포지션 매도 기간(약 2028-08 ~ 2029-09)에 차트를 만들면 생긴다
- **C4** — 원문의 배선 넷(종목 거르기 · 세로선 거르기 · 폭 · 바닥 앞 개월)은 무해하거나 예외로 멈춘다. 같은 빈틈이 `bottoms` 를 `row["peak"]` 로 바꾸는 변형을 통과시켜 ② 점 51/51 이 틀린 자리에 그려진다(전체 1,638건 통과)
- **C5** — `STOP_LEVELS_ETF_CONFIRMED = (0.25,)` 로 바꾸면 −25% 를 걸고도 「무손절 한 종만 낸다」를 싣고 `NOTE_STOP_BASE` 를 빠뜨린다. `TestStopNotes` 4건은 통과하고 notes 를 보지 않는 다른 3건만 실패한다
- **C6** — 확정 규칙의 대상은 코드 상수가 아니라 `규칙.md` §1 에만 있다. 규칙 값이 바뀌면(2026-10-04 사용자 결정 「규칙 값로 인해 오류가 발생될수 있다 … 이런건 고쳐야돼」) 문구가 엉뚱한 행을 규칙의 1배 기준으로 가리킨다
- 글자 규칙이 막거나 되돌릴 수 없는 결과에 물리는 설계: **해당 없음**
