- **템플릿 JS 는 테스트가 보지 못한다** — 축이 깨져도 전부 통과한다. 완화: 헤드리스 캡처를 눈으로 보고, HTML 속 데이터를 CSV 와 전수 대조한다(Phase 2)
- **차트와 커밋된 CSV 가 어긋날 수 있다** — 시세를 다시 받고 `run_halving_cycle.py` 를 안 돌리면 차트는 새 시세, CSV 는 옛 시세다. 완화: 머리에 데이터 기간을 찍고 가이드에 적는다. 막지 않는다(사용자가 고른 원천의 성질)
- **가이드 문구가 판정 · 기준선의 뜻을 틀리게 옮길 수 있다** — 완화: 게이트 값을 적지 않고 루트 `CLAUDE.md` 의 뜻을 그대로 옮긴다. 리뷰가 템플릿도 본다
- **계약 테스트(레이블 겹침 · 죽은 레이블 · 같은 값 두 파일)에 걸릴 수 있다** — 완화: `chart.py` 는 레이블을 정의하지 않는다(Context)
- **HTML 이 커진다** — 시제품 5.5MB 에 ③ ④ ⑤ 의 데이터가 더해진다. 실측해 §4.15 에 적는다
- **실행마다 약 45초** — 받아들인다(사용자 결정)
- `webbrowser` 가 WSL 에서 창을 못 열 수 있다 — 경로를 화면에 먼저 찍는다
- plotly 는 개발 의존성이다 — `poetry install --without dev` 인 환경에서는 차트 명령만 실패한다. 이 저장소의 설치 관용(개발 의존성 포함)에서는 걸리지 않아 받아들인다
