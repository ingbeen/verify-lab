## 3) 배경/맥락(Context)

### 현재 문제점 / 동기

`docs/strategy/투자금_결정.md` 는 2026-09-09 에 전면 개정됐으나, 이후 대화에서 **전제 다섯이 바뀌었다.**

1. **판정 축이 틀렸다.** 켈리분수 1/20 의 근거가 「계좌 최대낙폭 24%」였는데, 이 매매법의 **시장 노출 비율이 연 7.6%** 다. `.claude/rules/strategy.md` 「이벤트형에 곡선 지표를 붙이지 않는 이유」가 금지한 상황이며, 낙폭 24% 는 실제로 **26회 매매(약 8년)에 걸쳐** 일어나는 값이라 며칠짜리 매매의 자로 맞지 않는다.
2. **원금과 최대 손실액의 뜻이 모호했다.** §1.2 가 *"원금 — 그때그때 정한다"* 로만 적어 「총자산」과 「굴리는 투자금」이 구별되지 않았고, 최대 손실액이 **금액(1,000만원)** 이라 계좌가 변하면 규칙이 따라오지 않는다.
3. **집행 배수 전제가 좁았다.** §2.2 조견표가 「3배 상품 집행」을 전제로 쓰여 3배가 확정값처럼 읽히는데, 실제로는 **2배 또는 3배**이고 **KODEX 200 은 2배 상품만** 있다.
4. **대상 칸이 줄었다.** 사용자가 **KODEX 200 9월 제외**를 결정했다 (2026-09-10). 손익비 0.788(유일하게 1 미만) · t=1.16(60칸 선택 기준 2.35 미달) · 최악 1건이 22년 성과의 33% 라는 세 근거가 같은 곳을 가리켰다.
5. **책 분석으로 근거가 보강됐다.** 사용자가 제공한 「나는 AI로 급등주에 투자한다」 5부(pp. 258~291)를 분석해 성장률 항등식과 이산 켈리의 오용 사례를 얻었다.

그리고 **계산기가 없다.** 문서 §1 이 *"계산기: 구글 시트로 옮길 예정이다"* 로만 적혀 있고, 매번 일회용 스크립트로 계산해 왔다.

### 책 분석에서 얻은 것 (「나는 AI로 급등주에 투자한다」 5부, pp. 258~291)

| 발견 | 값 |
| --- | --- |
| **책의 `F = P − Q/B` 는 「투자 비중」이 아니라 「위험 비율」** | `E[log]` 직접 최대화로 확인. 책의 주식 예제(승률 60%·익절 +10%·손절 −5%)에서 F=0.4 인데 실제 최적 포지션은 **800%**. 어긋나는 배수가 정확히 `1 ÷ 손절폭` |
| **성장률 항등식** `2c − c²` | 하프 켈리 = 75% · **1/20 = 9.75%** |
| **켈리분수 = 우위가 진짜일 확률** | 비용 포함 시 `c* = π − 비용÷평균`. **1/20 = π 20.8%** (부트스트랩 실측 20.6%) |
| 마코위츠 효율적 투자선 | **적용 안 함** — 칸이 4개고, 자산 «사이» 배분이 아니라 현금 대비 «크기» |

**반증으로 기록**: DeMiguel·Garlappi·Uppal(2009)은 **균등가중(1/N)이 최적화를 이긴다**고 보고했다.
다루는 문제가 다르지만(여러 자산 사이 배분 vs 개별 베팅 크기) 남겨 둔다.
Chopra·Ziemba(1993)의 **「평균의 추정 오차가 분산의 오차보다 약 11배 중요」** 는
보류 중인 12월 두 칸 상관 논의를 재개할 때 직접 걸린다.

**미검증**: 「랜덤 가중치 몬테카를로는 편향돼 균등가중 지점에 봉우리가 생긴다」 —
한 갈래에서만 확인했다. 책이 가르치는 방식이 이것이나, 우리가 쓰지 않으므로 추적하지 않는다.
