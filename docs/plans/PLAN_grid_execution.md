## 7) 리스크(Risks)

- **하향 돌파를 빠뜨린다** — `종가 ≤ 레벨가` 만으로 판정하면 **첫날 현재가 아래가 전부 체결**되고 이후에도 같은 레벨을 매일 산다. 완화: 첫날 0건 테스트와 "아래에서 올라와 닿은 날" 테스트를 따로 박는다
- **중복 슬롯이 쌓인다** — 보유 중인 레벨을 거르지 않으면 같은 레벨이 여러 개 쌓여 노출이 조용히 커진다. 완화: 보유 레벨 집합을 인자로 받아 걸러내고, 사양서 §15.2 #12 를 테스트로 고정한다
- **격자 이탈 보너스를 안 센다** — 종가 체결 가정은 **항상 유리한 쪽으로만 벗어나고 급락일에 커진다.** 세지 않으면 지정가 운용과 비교가 성립하지 않는다. 완화: 체결마다 산출해 반환값에 담고, 0 이상임을 불변조건으로 건다
- **목표가를 매수 체결가 기준으로 잡는다** — 종가 체결이라 체결가가 레벨가보다 낮은데, 체결가에 g 를 붙이면 목표가가 격자에서 벗어나 **익절폭이 슬롯마다 달라진다.** 완화: 목표가는 조각 1 의 `target_price(k)` 만 쓰고 체결가를 인자로 받지 않는다
- **현금 부족 처리가 순서에 의존한다** — 활성 레벨 목록의 정렬이 흔들리면 어느 레벨이 체결되는지 달라진다. 완화: 조각 1 이 k 오름차순을 보장하고, 이 조각도 **정렬을 다시 확인**한 뒤 처리한다
