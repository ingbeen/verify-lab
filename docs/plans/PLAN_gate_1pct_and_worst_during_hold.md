## 3) 배경/맥락(Context)

### 현재 문제점 / 동기

**① 게이트가 느슨하다.** 회당 기대값 하한이 0.5% 라 후보가 너무 넓다. 사용자가 1.0% 를
최소치로 정했다. **0.5% 와 마찬가지로 거래비용 문턱이 아니라 사용자가 정한 최소치**이며,
비용을 반영하기로 하면 그것은 이 값 **위에** 더해진다 (`docs/조사/투자금_결정/규칙.md` §3.2).

**② 「최악」이 한 값뿐이라 실제로 감당할 손실이 안 보인다.** 지금 `최악(%)` 은 **청산 시점의
수익률** 중 가장 나쁜 것이다. 보유 중에 얼마나 밀렸는지는 어디에도 없어서, 매도 시 −5% 인
칸과 보유 중 −15% 까지 밀렸다가 −5% 로 끝난 칸이 **표에서 구별되지 않는다.**
후자는 회당 기대값 대비 감당해야 할 손실이 훨씬 커 같은 성적이 아니다.

**③ 게이트를 올리면 확정 집행 칸이 걸린다 — 먼저 재서 알고 들어간다.**
현 산출물(`시기 = 전체` 행)에 1.0% 를 적용한 결과는 아래와 같다.

| 매매법 | 후보 (0.5%) | 후보 (1.0%) |
| --- | ---: | ---: |
| 옵션 만기일 | 387행 | **95행** |
| 월말 진입 | 103행 | 85행 |
| 역방향 | 38행 | 34행 |

🔴 **옵션 만기일 확정 4칸**(`docs/매매/옵션_만기일/규칙.md` §1.1)

| 칸 | 손절 −5% 회당 | 무손절 회당 | 1.0% 게이트 |
| --- | ---: | ---: | --- |
| DIA 9월 아래 | **+1.00%** | +0.94% | −5% 행만 통과 |
| SPY 9월 아래 | +0.94% | +0.88% | **미달** |
| DIA 12월 위 | +0.90% | +0.90% | **미달** |
| SPY 12월 위 | +0.71% | +0.71% | **미달** |

역방향 확정 4행(회당 +1.50 ~ +4.74%)과 월말 권고 달(9·12월)은 전부 유지된다.
**이 사실을 규칙 문서에 적되 집행 칸은 사용자가 정한다** (비목표 3).

| **지수 대상의 보유 중 최악이 종가 기준이라 실제보다 얕다** | 값은 그대로 내되 `summary.json` 의 `notes` 와 규칙 문서에 그 사실을 적는다. 지수 행은 `손절선(%) = 손절불가` 로 한 컬럼에서 구별된다 |
| 장중 여부를 넘기는 인자를 **호출처가 빠뜨린다** | 기본값을 두지 않아 그 자리에서 실패하게 만든다. `tradable`·`measurable` 과 같은 관용이다 |
| 후보가 줄어 **「후보가 가장 많아지는 손절선」이 더 눈에 띈다** | 손절선 선정 기준은 「평평한 구간 + 최악 통제」이지 후보 수가 아니다 (`.claude/rules/trading.md`). 이번 작업에서 **손절선을 재선정하지 않는다** |
| 문서 15곳 중 일부가 낡은 값으로 남는다 | **숫자를 걷어내므로 낡을 값 자체가 없어진다**(결정 ⑧). 마지막 Phase 에서 다시 grep 해 남은 것이 **설계·결과 문서의 그때의 기록뿐**임을 확인한다 |
| **읽는 사람이 값을 보려면 코드를 열어야 한다** — 지금 규칙이 인용을 허용하던 이유다 | 상수 이름과 **경로를 함께** 적어 한 번에 찾아가게 한다. 값이 실제로 필요한 자리는 판정을 직접 하는 자리이고, 그때는 산출물의 `1차 판정` 컬럼이 이미 답을 준다 |
| **결정 ⑧ 을 「기록」 문서에까지 적용해 과거를 지운다** | 예외 둘(`설계.md` 결정 표 · `결과.md` 재실행 기록)을 계획서와 `.claude/rules/trading.md` 양쪽에 명시한다. 「0.5% 였다가 올렸다」가 사라지면 같은 논의를 다시 한다 |

## 8) 메모(Notes)

- **게이트 값의 SoT 는 `measure/screening.py` 하나다.** 문서가 값을 인용하는 것은 되지만,
  **값을 바꿀 때는 코드부터 고치고 문서가 따라간다** (`.claude/rules/trading.md`)
- **「최악」이 둘이 되는 것은 이름 개명이 아니라 축 추가다.** `최악(%)` 의 뜻은 바뀌지 않으므로
  이미 그 값을 인용한 결과·규칙 문서의 수치는 그대로 유효하다
- **`보유 중 최악 ≤ 결과 수익률` 이 항상 성립한다** — 청산가는 보유 중에 실제로 지난 가격이고,
  장중 최저점은 그것을 포함한 구간의 최솟값이기 때문이다. 갭 청산(시가가 손절선 아래)도
  그 시가가 그날 고가·저가 사이에 있으므로 예외가 아니다. **이것이 Phase 0 의 불변조건이다**
- 이번 계산의 예측치는 **현 산출물에서 잰 것**이고 데이터 기간은 각 매매법 `summary.json` 의
  `datasets` 가 말한다. 시세를 재수집하면 달라진다
