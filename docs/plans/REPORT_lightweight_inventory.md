| **B. 「위치만」 원칙 + 고정 어휘 상태 칸 (추천)** | ① 매매법 이름표 하나 — 이름 · slug · 등급 · 코드 · 문서(링크 텍스트는 「설계 · 결과 · 규칙」) · **상태(고정 어휘 하나)** ② 매매법 폴더 밖에서 찾기 어려운 지식만 「찾는 것 → 문서 · 절 제목」 표 ③ 규칙 문서 표는 「담당 한 줄 · 로드 방식」 ④ reference 는 한 줄 링크 목록 | 요약이 없으니 낡을 것이 없다. 「무엇」은 각 문서 머리말이 말한다. 테스트 무변경 | 문서 내용을 INDEX 에서 미리 볼 수 없다 (문서 머리말을 연다) |
| C. 자동 생성 | 폴더 트리와 각 문서 제목에서 INDEX 를 스크립트로 생성 | 절대 안 낡는다 | 새 코드·새 검증 대상. 지금 규모에 과함 (YAGNI) |
| D. 폴더 단위 링크 | 파일 대신 폴더만 링크, 테스트를 폴더 단위로 완화 | 가장 짧다 | 테스트 코드 수정, 파일 단위 누락 검사를 잃는다 |

**추천 B.** 사용자가 제안한 키워드는 **「상태」 칸의 고정 어휘**로 흡수한다 — 자유 태그는 늘어나고 어긋나지만,
등급과 짝을 이루는 닫힌 어휘(예: `확정 규칙` · `재는 중` · `걸지 않음` · `채택 안 함` · `성질 조사`)는 바뀔 일이 적고 한 단어로 읽힌다.
