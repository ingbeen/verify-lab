## 3) 배경/맥락(Context)

### 현재 문제점 / 동기

**① 기존 「방향」 축은 부호만 본다.**

`breakdown.py` 의 방향 축은 `1배 수익률 > 0` 이면 「오름」, `< 0` 이면 「내림」, **정확히 0** 이면
「보합」이다. 그래서 **+1% 와 +50% 가 같은 칸에 들어간다.** 경로 효과는 크기의 함수이므로
이 축으로는 «완만한 상승에서 가장 많이 깎인다» 가 보이지 않는다.

**② 실측하면 U자다** (2026-09-05 10:27 실행 산출물, 오분위로 시산):

| QLD 1년 | 시장 평균 | 경로 효과 | | SSO 1년 | 시장 평균 | 경로 효과 |
| --- | --- | --- | --- | --- | --- | --- |
| 하위20% | −12.83% | −1.93%p | | 하위20% | −14.56% | −0.73%p |
| **20~40%** | **+9.48%** | **−4.04%p** | | **20~40%** | **+5.07%** | **−3.60%p** |
| 40~60% | +19.53% | −0.86%p | | 40~60% | +12.85% | −1.72%p |
| 60~80% | +27.41% | +2.84%p | | 60~80% | +17.88% | −0.58%p |
| 상위20% | +42.27% | **+7.76%p** | | 상위20% | +29.69% | **+5.23%p** |

**양끝이 높고 가운데가 낮다.** 큰 하락에서는 매일 리밸런싱이 포지션을 줄여 덜 잃고,
큰 상승에서는 복리로 앞선다. **완만한 상승 구간에서만 깎인다.**

**③ 검증 #9 가 같은 구조를 국내에서 확인했지만 대상이 사용자와 다르다.**

`docs/research/선물_대_레버리지_ETF.md` §7 이 「그대로 두기」와의 차이로 같은 현상을 냈다.
**검증 #8 의 `경로 효과 = 이론 경로 − 단순 배수 기대치` 가 곧 그 차이다** —
`단순 배수 기대치 = 배수 × 1배 수익률` 이 「계약 수를 고정하고 그대로 두기」와 같은 값이다.
같은 축을 두 검증이 다른 이름으로 부르고 있으므로, **#8 쪽에 수치를 채우고 #9 는 그것을 참조한다.**
