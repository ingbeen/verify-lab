## 2) 비목표(Non-Goals)

- **매매 규칙을 확정하지 않는다.** 손절선 값·채택 칸·자금 배분은 **격자를 본 뒤 사용자가 정한다.**
  이 계획서는 판단 재료를 만들 뿐이며, 재료를 만들면서 값을 고르면 측정의 원칙 1 을 어긴다
- **`docs/strategy/` 규칙 문서를 아직 쓰지 않는다.** 격자 결과 없이 쓰면 근거 없는 값이 박힌다
- **채택 범위를 코드로 좁히지 않는다.** 등급 3/3 **7칸 전부**를 돌린다. 비용 후 +0.14% 인
  DIA 6월도 포함한다 — 손절을 넣으면 칸마다 다르게 깎이므로 지금 자르면 순서가 거꾸로다
- **세금·인버스 ETF 상품 손익을 계산에 넣지 않는다.** 사용자가 「세전만 고려」·「인버스는
  직접 처리」로 확정했다. 수익률은 **원지수 부호를 뒤집은 값**이며 인버스 상품의 손익이 아니다
- **`studies/option_expiry/` 의 맨몸 판정을 바꾸지 않는다.** 손절은 `strategy/` 계층의 것이고,
  측정 계층에 손절이 들어가면 이 저장소가 「측정소」라는 정체성이 검증마다 흐려진다
  (`.claude/rules/strategy.md` 의 폴더 경계)
- **역방향 매매의 확정 규칙(−5% · D+2)과 그 성적을 바꾸지 않는다.** 공유 함수를 건드리되
  **기본값으로 기존 동작이 그대로 유지되어야 한다**
- **시세를 재수집하지 않는다.** 기존 `storage/market/` 파일을 그대로 쓴다 —
  재수집하면 `docs/research/옵션_만기일.md` 의 수치가 그 시점부터 재현되지 않는다
- **진입가를 바꾸지 않는다.** 종가 매수는 사용자가 확정했고 익일 시가 진입은 다른 매매다

## 3) 배경/맥락(Context)

### 현재 문제점 / 동기

- `docs/research/옵션_만기일.md` 가 등급 3/3 **7칸**을 후보로 냈지만 **전부 맨몸 성적**이다.
  `.claude/rules/strategy.md` 는 **모든 매매 규칙에 손절을 요구**하는데, 이 검증에는
  손절 코드도 격자도 없어 규칙을 세울 수 없다
- 역방향 매매는 같은 상황을 **손절 격자 135조합**으로 풀었고, 그 표(§3.1)가
  「−4%~−10% 가 평평하다 → 값 선택이 결과를 만들지 않는다 → 갭손절 0건의 첫 지점으로 고른다」는
  **구조적 근거**를 만들어 냈다. 같은 절차를 이 매매에 적용한다
- 다만 **역방향의 −5% 를 그대로 가져올 수 없다.** 보유가 1~2거래일 대 **5~6거래일**이라
  손절선이 닿는 빈도와 갭 노출 횟수(1~2회 대 5~6회)가 다르다. 그리고 역방향 문서 §5.4 에
  **「갭손절 0건」이라는 근거가 표본을 31건 늘리자 깨졌다**는 기록이 이미 있다
- 사용자가 **회당 기대값만 적은 표는 크기 감각을 주지 못한다**고 지적해 루트 `CLAUDE.md` 에
  **측정의 원칙 16** 을 신설했다. 그런데 `candidates.csv` 에는 합산 컬럼이 없어
  **문서의 규칙과 코드의 산출물이 갈라져 있다**
