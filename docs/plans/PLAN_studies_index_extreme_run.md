## 6) 단계별 계획(Phases)

### Phase 0 — 조합 순회와 신호군 계약을 테스트로 먼저 고정(레드)

> **이 조각이 틀리는 방식은 "결과가 그럴듯하게 나오는 것"이다.** 조합 하나가 빠지거나 사건 수가
> 방향별로 잘못 세어져도 예외는 나지 않는다. 축의 개수와 사건 수 산식을 손계산으로 박아 둔 뒤 구현한다.

**작업 내용**:

- [x] `tests/test_studies_runner.py` — 조합 축
      - 신호군 축이 **테스트 × 파라미터 × 시작연도 × 방향 × 구간 × 데이터셋**의 곱과 같다
      - 식별 컬럼(종목·가격기준·테스트·파라미터·시작연도·방향·구간)이 **CSV 4개 전부**에 붙는다
      - **신호 0건인 신호군은 집계표에서 빠지고 그 사실이 요약에 남는다** (표본 보존 — 조용히 사라지면 안 된다)
- [x] 사건 수 병기
      - 사건 번호는 **폭등·폭락을 합친 목록**에 매긴다
      - 방향별 표의 사건 수 = **그 방향 신호가 걸친 서로 다른 사건 수** (손계산으로 고정)
- [x] 베이스라인 기간
      - 모집단이 **신호군의 집계 시작일 이후로 잘린다** (모집단 표본 수 손계산)
      - 조건부 모집단은 200일선을 **전 기간으로 쌓은 뒤** 날짜로 거른다 — 먼저 자르면 창이 다시 찬다
      - 판정 불가 일수가 요약에 남는다
- [x] 시대 구간
      - 구간 필터는 **신호 선택의 끝**을 자르며, 시세를 자르지 않는다 (신호 수 손계산)
      - 기본 시작연도에만 구간 2개가 추가된다
- [x] 경계 조건
      - 200일선 판정이 한 번도 되지 않는 짧은 데이터 — 조건부 모집단이 0건이어도 예외 없이 사유가 남는다
      - 측정 구간 끝이 데이터를 넘는 신호가 섞인 경우 — 제외 건수가 보존된다

## 7) 리스크(Risks)

- **집계 시작일을 함수 밖에서 자를 위험** — 시세를 먼저 잘라 넘기면 확장창 순위가 그 지점부터 다시
  쌓이고 걸쳐 있던 연속이 끊긴다. **결과는 달라지는데 예외가 나지 않는다.** 시작일은 언제나
  이벤트 정의 함수에 `start_date` 로 넘기고, 시대 구간의 끝 자르기도 **신호 선택**에만 적용한다
- **신호 0건 신호군에서 예외가 터질 위험** — `excess` 는 두 집계의 칸 구성이 다르면 `ValueError` 를 내고,
  `save_table` 은 빈 표를 거부한다. QQQ N=10 연속 하락처럼 0건인 칸이 실제로 존재하므로,
  **집계에서 빼되 뺐다는 사실을 요약에 남긴다**
- **사건 수를 방향별로 따로 묶을 위험** — 그렇게 하면 2008년 사건에서 폭등 2건·폭락 2건이 4사건이 되어
  결정 ③ 이 드러내려던 **비독립성이 오히려 숨는다.** 번호는 합친 목록에 매기고 방향별로는 "걸친 사건 수"를 센다
- **베이스라인 모집단이 신호군과 다른 기간을 볼 위험** — 초과분에 "그 사이 시장이 어땠는가"가 섞여
  시작 시점 민감도 체크가 신호가 아니라 시장을 재게 된다. 모집단도 같은 창으로 자른다
- **화면과 CSV 의 숫자가 갈릴 위험** — 터미널용으로 따로 가공하면 반올림 시점이 갈린다.
  **저장한 표시용 프레임에서 발췌만** 한다
- **수정주가 계열의 순위 축적이 짧다** — 2014-05-22 부터만 존재하므로 시작연도 4개가 모두 같은 실질
  시작일이 되고, 테스트 A 의 순위 기준선이 원본가보다 훨씬 느슨하다. 조합은 그대로 돌리되
  **이 사실을 요약과 결과 문서 한계에 적는다**
- **2026년 국내 신호의 측정 구간이 아직 끝나지 않았다** — 국내 등락 상위 10위의 60%가 2026년이며
  긴 구간이 제외로 빠진다. 제외 건수가 표에 남으므로 숨지 않지만, 해석에서 반드시 지적한다
- **실행 시간** — 순열 검정 1회 0.77초 기준으로 조합 전체가 10분 내외다. 기간을 자른 모집단은 더 작아
  이보다 짧을 것으로 보지만, 실측해 기록한다. 오래 걸린다고 조합을 쪼개지 않는다
