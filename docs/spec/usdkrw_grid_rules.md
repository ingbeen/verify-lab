## 2. 핵심 이론 전제

### 2.1 261240은 "환전"이 아니라 "환전 + 달러 예치"의 대체재

261240은 현물이 아니라 **미국달러선물 최근월물**을 추종한다.

```
선물가격 = 현물 × (1 + 원화금리 × t) / (1 + 달러금리 × t)
```

달러금리 > 원화금리이면 선물이 현물보다 낮게 형성되고(백워데이션), 롱 포지션은 롤오버 시 이익을 얻는다. 이 롤 수익이 **금리차와 동일**하다.

커버드 금리평형에 의해 다음이 등가다.

| A | B |
|---|---|
| 달러 현물 + 달러 이자 | 달러선물 롱 + 원화 담보 이자 |

**→ 261240 내부에 달러 RP 이자에 해당하는 것이 이미 내장되어 있다.**

| 비교 기준선 | 결과 |
|---|---|
| 원달러 현물 vs 261240 | ❌ 캐리만큼 계속 벌어짐 → "대체 불가"로 오판 |
| (현물 + 달러금리 − 원화금리) vs 261240 | ✅ 총보수만큼만 벌어져야 정상 |

### 2.2 레버리지 조달비용의 부호

```
순 조달비용 = (빌린 돈의 이자) − (빌린 돈으로 산 자산이 벌어주는 수익)
```

| | TQQQ (참고) | 261250 |
|---|---|---|
| 빌리는 통화 | 달러 | **원화** |
| 사는 자산 | 나스닥100 | **달러** |
| 산 자산의 수익 | 배당 약 0.6% | **단기금리 전액** |
| 순 조달비용 | **항상 (+)** | **금리차에 따라 (+) 또는 (−)** |

**261250에 명시적 TRS/스왑 수수료는 없다.** KRX 장내 선물로 직접 2배 복제하므로 계약 상대방이 없다. 조달비용은 선물 가격에 이미 반영되어 있다.

| 금리 관계 | 261250 영향 |
|---|---|
| 달러금리 > 원화금리 | 2배로 **유리** (음의 조달비용) |
| 원화금리 > 달러금리 | 2배로 **불리** (스왑비용처럼 작동) |

**→ 한미 금리차 부호별 분리 분석 필수.**

### 2.3 종가 기반 항목은 더하지도 빼지도 않는다

| 비용 | 부담 주체 | 반영 위치 | 별도 차감 |
|---|---|---|---|
| 운용보수 | ETF 펀드 | NAV → 주가 | ❌ |
| 내부 선물 매매비용 | ETF 펀드 | NAV → 주가 | ❌ |
| 롤오버 스프레드 | ETF 펀드 | NAV → 주가 | ❌ |
| 변동성 감쇠 | — | NAV → 주가 | ❌ |
| 금리차 캐리 | — | NAV → 주가 | ❌ |
| **위탁수수료** | **내 계좌** | 주가와 무관 | **✅** |
| **슬리피지** | **내 계좌** | 주가와 무관 | **✅** |

**판단 기준: 펀드 자산이 줄었는가, 내 현금이 줄었는가.**

위탁수수료는 운용사가 아니라 **증권사가 내 계좌에 매기는 요율**이므로 종목과 무관하게 동일하다. 환전 스프레드가 매매기준율에 안 들어 있는 것과 같은 구조다.

### 2.4 그리드 수익의 이론적 크기

그리드 매매는 델타헤지된 롱 감마 포지션과 등가이며 수익은 실현 변동성에 비례한다.

```
연간 그리드 수익 ≈ ½ × σ² × (g − c) / g²  × 노출액
```

원달러 σ ≈ 7~8%에서 **그리드 매매 기여는 총자산 대비 연 0.5% 내외**로 매우 작다. **수익의 대부분은 이자에서 나온다.**

### 2.5 익절폭의 이론적 최적값

위 식을 g로 미분하여 0으로 놓으면:

```
g* = 2c        (최적 익절폭 = 왕복비용의 2배)
```

| 익절폭 | 비용 배수 | 상대 수익 |
|---|---|---|
| 0.6% | ×1.5 | 0.556 |
| **0.8%** | **×2** | **0.625** ← 최대 |
| 1.2% | ×3 | 0.556 |
| 1.6% | ×4 | 0.469 |
| 2.4% | ×6 | 0.347 |

작으면 회전은 늘지만 비용 비중이 커지고, 크면 건당 이익은 늘지만 회전이 제곱으로 줄어든다.

경로별 왕복비용이 다르므로 이론 최적값도 다르다.

| 경로 | 왕복비용 | 이론 최적 g |
|---|---|---|
| 환전 | 0.40% | 0.80% |
| 261240 / 261250 | 0.23% | 0.46% |

**비교를 위해 동일 g를 적용하되**, ETF가 더 작은 g에서 유리하다는 점을 결과 해석에 반영한다.

## 3. 격자 (Lattice)

### 3.1 정의

```
레벨_k = 1000원 × (1 + g)^k        k는 정수, 음수 허용
```

**앵커 1000원은 임의 상수**이며 결과에 영향을 주지 않는다. 500원이나 1200원으로 바꿔도 동일하다.

**레벨 가격은 영구 고정이다.** 범위가 어떻게 변하든 레벨 가격표는 바뀌지 않으며, 범위는 **어느 레벨을 활성화할지만** 결정한다.

### 3.2 왜 고정 격자인가

범위 하단 기준으로 레벨을 재생성하면, 재조정 때마다 격자가 미세하게 어긋나 **기존 보유 슬롯 바로 옆에 유령 레벨이 생기고 중복 매수가 누적된다.** 고정 격자는 이 문제가 구조적으로 발생하지 않는다.

### 3.3 매도 목표가

```
목표가 = 레벨_(k+1) = 매수 레벨의 바로 위 칸
```

등비 격자이므로 목표가가 자동으로 정확히 한 칸 위가 된다. **실제 매수 체결가와 무관하게 격자에 고정된다.**

### 3.4 k 범위

전 기간 백테스트 시 k ≈ **−25 ~ +60** (g=1.2% 기준, 약 85개 칸). g가 작아지면 칸 수가 늘어난다.

동시에 활성인 것은 그 중 일부다.

## 4. 동적 범위

### 4.1 산출

```
범위 = 과거 12N개 월평균 종가의 min ~ max      (당월 제외)
```

| N | 참조 개월 | 예: 2020-03 재조정 |
|---|---|---|
| 1 | 12개 | 2019-03 ~ 2020-02 |
| 3 | 36개 | 2017-03 ~ 2020-02 |
| 5 | 60개 | 2015-03 ~ 2020-02 |
| 7 | 84개 | 2013-03 ~ 2020-02 |

**월평균 채택 근거**: 일종가 min/max는 하루짜리 스파이크가 N년간 경계를 지배하고, 윈도우에서 빠질 때도 급격히 변한다. 월평균은 진입·이탈 양쪽을 완만하게 하며 **윈도우 엣지 효과를 함께 완화**한다. 파라미터도 추가되지 않는다.

**대가**: 월평균은 정의상 월중 저점보다 높다. 급락 시 **1~4% 아래를 못 산다.** 이 손실은 측정 대상이다(§10).

**min/max 채택 근거** (백분위·kσ 대비): 자유 파라미터가 N 하나만 남는다. 백분위는 "왜 10인가", kσ는 "왜 2인가"와 정규성 가정이 추가된다.

### 4.2 최소 범위폭 강제

```
중간가 = √(상단 × 하단)                    (기하평균)
현재폭 = 상단 / 하단 − 1

if 현재폭 < 20%:
    상단 = 중간가 × √1.2
    하단 = 중간가 ÷ √1.2
```

**목적**: 장기 횡보 시 범위가 좁아져 활성 레벨이 과도하게 줄고 슬롯 하나가 거대해지는 것을 방지한다.

**성격**: 룩어헤드는 아니다(미래 데이터 미사용). 다만 원달러 변동폭에 대한 사전 지식이 반영된 값이므로 견고성 검사로 방어한다.

### 4.3 재조정

| 항목 | 규칙 |
|---|---|
| 주기 | **월 1회** (매월 첫 거래일) |
| 사용 데이터 | **t−1일까지만** |
| 기존 보유 슬롯 | **목표가 유지, 강제 청산 없음** |
| 재조정 대상 | **미체결 레벨의 활성/비활성 토글만** |
| 신규 활성 레벨 | 즉시 매수 금지, 하향 돌파 대기 |

기존 슬롯을 재조정하면 "재조정할 때마다 손익이 확정되는" 인공 수익원이 생긴다.

### 4.4 범위 변화 시 거동

| 상황 | 처리 |
|---|---|
| 상단 확대 | 위쪽 레벨 활성화. 현재가가 그 아래면 즉시 영향 없음 |
| 상단 축소 (미체결) | 비활성화. **영향 없음** |
| 하단 축소 (미체결) | 비활성화. **커버리지 축소 — 위험** |
| 보유 슬롯이 범위 밖 | 보유 유지, 목표가 유지, 매도 후 재활성화 안 됨 |

**상단 축소는 무해하고 하단 축소가 위험하다.** 상단 레벨은 어차피 "내려오면 살 곳"이라 꺼져도 잃는 것이 없다.

### 4.5 알려진 구조적 약점 (사전 인정)

롤링 min/max는 상승 추세를 따라 올라간다. 하단이 매년 상승하며 고점 부근에서 계속 매수하게 되고, 추세 반전 시 전 슬롯이 동시에 물린다.

**1단계에서는 방어하지 않고 측정만 한다.** 수정책(래칫, 이동속도 제한)은 전부 새 파라미터를 추가한다.

## 5. 자금 배분

### 5.1 3구간 차등

```
위치 = ln(레벨가 / 하단) ÷ ln(상단 / 하단)      → 0(하단) ~ 1(상단)
```

등비 격자이므로 로그로 측정한다.

| 구간 | 위치 | 배수 |
|---|---|---|
| 하단부 | 0.00 ~ 0.33 | **1.5** |
| 중간부 | 0.33 ~ 0.67 | **1.0** |
| 상단부 | 0.67 ~ 1.00 | **0.5** |

**±0.5 대칭 채택 근거**: 자유 파라미터가 하나로 줄어든다. 1.5/1.0/0.7 같은 비대칭은 두 숫자를 각각 정당화해야 한다.

**목적과 대가**: 비쌀 때 적게, 쌀 때 많이 산다. 다만 **회전이 잦은 상단부 금액이 줄어 평시 그리드 수익은 감소**한다. 균등 대비 우열은 백테스트가 판정한다.

### 5.2 슬롯 금액 산출 — 매일 재계산

```
슬롯금액_k = min( 총자산 × 배수_k ÷ Σ(활성레벨 배수),  총자산 × 8% )

잉여 = Σ(계산값 − 실제배정)  → 원화현금 잔류, 파킹 이자 수취
```

**매일 종가 확정 후 재계산하여 그날 매수에 적용한다.** 월 1회 재계산이면 급락하는 달에 첫날 금액으로 마지막 날까지 매수하게 된다.

**총자산은 시가평가 기준**이다(§8). 환율 하락 시 총자산이 줄어 슬롯이 작아지는 부작용이 있으나, 하단부 배수 1.5가 이를 상쇄한다.

### 5.3 슬롯 상한 8%

**목적**: 범위가 좁아졌을 때 슬롯 하나가 거대해지는 것을 방지한다.

**8% 근거**: 최소폭 20% 조건에서 하단부 슬롯이 최대 9.2%까지 커진다. 그 바로 아래에서 묶어 **정상 상황(활성 20레벨 이상, 하단부 7.3%)에서는 발동하지 않고** 비정상적으로 좁을 때만 작동한다.

**알려진 부작용**: 상한이 걸리면 하단부와 중간부가 같은 금액이 되어 **차등이 소멸하고 사실상 균등 그리드로 퇴화한다.** 좁은 범위에서 노출을 줄이는 것이 주목적이므로 이 퇴화는 수용한다. 대신 상한 발동 횟수와 현금 잔류율을 기록한다.

## 6. 체결 규칙

### 6.1 매수

```
조건: 전일 종가 > 레벨가  AND  당일 종가 ≤ 레벨가        (하향 돌파)
체결: 당일 종가
```

**하향 돌파 조건이 필요한 이유**: "종가 ≤ 레벨가"만으로는 백테스트 첫날 현재가 아래 레벨이 전부 동시 체결된다. 전일 종가는 "위에서 내려왔는지" 확인용일 뿐이며, **판정도 체결도 모두 당일 종가**다.

### 6.2 매도

```
조건: 당일 종가 ≥ 목표가                 (보유 슬롯만 대상)
체결: 당일 종가
```

### 6.3 다중 체결

**하루에 여러 레벨이 뚫리면 전부 체결한다.** 체결가는 모두 당일 종가로 동일하되, **목표가는 각 레벨의 격자 위치에 따라 다르다.**

예시: 전일 1,310 → 당일 1,280 (g=1.2%)

| 슬롯 | 격자가 | 매수가 | 목표가 | 실질 수익 |
|---|---|---|---|---|
| k=22 | 1,300.2 | **1,280** | 1,315.8 | **+2.80%** |
| k=21 | 1,284.8 | **1,280** | 1,300.2 | **+1.58%** |

매도도 동일하다. 목표가 1,315.8인데 종가가 1,330이면 1,330에 체결된다.

### 6.4 격자 이탈 보너스 — 별도 집계 필수

종가 체결 가정에서는 **항상 유리한 쪽으로만 벗어난다.** 지정가 주문이었다면 정확히 격자가에 체결됐을 것이다.

```
이탈 보너스 = 실제 실현손익 − (격자 기준 g × 슬롯금액)
```

급락일에 구조적으로 커지므로, 총수익의 몇 %를 차지하는지 반드시 기록한다. 이를 제외해야 실제 지정가 운용과 비교가 성립한다.

### 6.5 기타

| 항목 | 규칙 |
|---|---|
| 레벨 재활성화 | 매도 즉시 (하향 돌파 대기 상태로 복귀) |
| 자금 소진 | 매수 중단 + **로그 기록** (버그 아님, 측정 대상) |
| ETF 주식 수 | **정수 단위** (반올림 오차 반영) |
| 환전 단위 | 소수점 허용 |
| 미국 휴일 | T-bill 전일값 이월 |
| 한국 휴일 | 거래 없음, 이자만 발생 |

### 6.6 실제 운용 시각 (참고)

> 백테스트는 **일별 종가** 기준으로 계산하고 모든 결과·차트·지표를 종가 기준으로 표기한다.
>
> 실제 운용 시에는 환전 우대 시간(~15:30) 내인 **15:20에 판정 및 실행**한다. 10분 간 원달러 변동(약 0.05~0.1%)은 슬리피지 편도 0.1% 가정에 포함된 것으로 본다.

## 7. 하단 이탈 대응 — A / B 병행

| | **A** | **B** |
|---|---|---|
| 규칙 | 월평균 하단 유지, 이탈 시 매수 중단 | 이탈 즉시 격자를 아래로 한 칸씩 연장 |
| 파라미터 추가 | 없음 | 없음 (g 재사용) |
| 자금 처리 | 현금 유휴 | 매일 재정규화로 자동 축소 배분 |
| 결과 | 낮은 노출, 낮은 MDD | 낮은 평균단가, 높은 MDD |

**둘 다 실행하여 비교한다.** 파라미터가 아니라 설계 대안이므로 하나를 고르지 않는다.

**B안 추가 측정 항목**

| 항목 |
|---|
| 격자 연장 발생 횟수 / 최대 연장 칸 수 |
| 현금 완전 소진 발생 여부 및 시점 |
| 소진 시점의 평가손실률 |
| **A안 대비 평균단가 개선폭** |
| **A안 대비 MDD 악화폭** |

마지막 두 줄이 B안의 손익계산서다. 평균단가를 2% 낮추는 대가로 MDD가 8% 나빠졌다면 B는 실패다.

**자산 추가 금지 근거**: 허용하면 "돈이 무한하면 언젠가 이긴다"는 자명한 결론으로 수렴한다. 소진 시점 측정이 백테스트의 핵심 산출물인데 그것을 없애버린다. 또한 "바닥에서 추가 투입"은 사후 지식이다.

## 8. 평가 — 전 자산 원화, 일별

```
총자산(일별) = 원화현금
             + Σ(슬롯 달러금액 × 당일 매매기준율)      ← 매일 변동
             + ETF 시가평가액
```

| 규칙 | 내용 |
|---|---|
| 평가 통화 | **원화** |
| 평가 주기 | **일별** |
| 평가 환율 | **매매기준율 그대로** (스프레드 미적용) |
| 스프레드 적용 | **실제 환전 시점에만** |

평가 때마다 스프레드를 차감하면 매일 미실현 손실이 과대계상된다.

**미실현 평가손익은 반드시 반영한다.** 실현손익만 집계하면 그리드 자산곡선은 항상 우상향한다(매도는 무조건 이익 실현, 손실은 미실현으로 잔류). 2009~2014 하락장에서도 실현 기준 곡선은 예쁘게 올라가지만 실제 계좌는 반토막이다.

### 9.1 환전 (달러 현금 잔고 항상 0)

```
매수: 토스 원화 → 환전(0.2%) → 달러 → [한투 이체] → 전액 RP 매수
보유: RP 평가액 일할 증가
월말: 이자분만 부분해지 → 환전(0.2%) → 원화현금        (원금 달러는 슬롯에 유지)
매도: RP 전액해지 → [이체] → 환전(0.2%) → 원화현금
```

**이자 발생일수**

```
이자일수 = 보유일수 − 1        (RP는 매수일·매도일 당일 이자 미지급)
```

| 보유 | 이자일수 | 손실률 |
|---|---|---|
| 1일 | 0일 | 100% |
| 5일 | 4일 | 20% |
| 30일 | 29일 | 3.3% |

**단기 회전일수록 손실이 크다.** 익절폭이 작은 설정에서 이 효과가 커지며, g=0.8%가 이론값만큼 좋게 나오지 않을 수 있다. 그것이 정상이다.

월말 이자 이동도 동일하게 **당일 미포함, 전일까지 누적분**만 인출한다.

**이체 가정**

| 항목 | 값 |
|---|---|
| 이체 수수료 | **0원** |
| 이체 소요 | **당일 완료** (영업시간 09:00~15:30 내 실시간 수준) |
| 이체 실패/지연 | 없음 |

### 9.2 ETF

```
매수/매도: 당일 종가 체결, 위탁수수료 + 슬리피지 차감
보유:      캐리·보수·롤오버·감쇠 전부 종가에 내재  (별도 가감 금지)
매도:      차익 15.4% 과세
```

**261250은 슬롯 금액 전액 투입** (노출 2배).

### 11.1 소스 (단일 지정)

| 용도 | 지표 | 소스 | 가용 시작 |
|---|---|---|---|
| 환율 | 매매기준율 종가 | 서울외국환중개 / ECOS | 1990년대 |
| 달러 금리 | **미국 3개월 T-bill (DTB3)** | FRED | 1954 |
| 원화 금리 | **CD 91일물** | 한국은행 ECOS | 1990년대 |

| ETF 2배 | 261250 수정 종가 | KRX | 2016.12 |

**T-bill 선정 근거**: SOFR는 2018년 시작이라 장기 백테스트 불가. T-bill은 전 기간 커버, 무위험 단기금리로 RP 수익의 상한에 해당, 일별 무료 제공.

### 11.2 실수령 금리 모델

**달러 RP**

```
RP금리 = max( T-bill − s(T-bill),  0.40% )

s(x) = 1.00%p    if x ≥ 4.0%
     = 0.60%p    if 2.0% ≤ x < 4.0%
     = 0.30%p    if 0.5% ≤ x < 2.0%
     = 0.10%p    if x < 0.5%
```

**하한이 존재하는 이유**: 국내 증권사는 해외주식 결제·파생 헤지로 달러가 상시 부족하고, 원달러 스왑베이시스가 만성 마이너스라 달러 조달 비용이 미국 정책금리보다 비싸다. RP는 증권사 입장에서 싼 달러 조달 창구이므로 미국 금리가 0이어도 프리미엄을 얹을 여력이 있다.

**검증**

| T-bill | 모델 결과 | 실측 |
|---|---|---|
| 5.00% | 4.00% | 4.00~4.05% ✅ |
| 3.60% | 3.00% | 3.4% 안팎 |
| 1.00% | 0.70% | 0.5~1.3% (1년물) ✅ |
| 0.25% | **0.40%** | 0.3~0.7% ✅ |

**원화 파킹**

```
파킹금리 = max( CD91 − 0.30%p,  0.50% )
```

파킹통장·CMA는 기준금리 0.5% 시기에도 연 0.5~1.0%를 지급했다.

**영향**: 2009~2015 제로금리 구간은 원달러가 1,570 → 1,008로 빠진 그리드 최악 국면인데, 하한이 없으면 이자를 0으로 처리해 **손실을 실제보다 과대평가**한다.

### 11.3 데이터 품질 요구사항

| 항목 | 규칙 |
|---|---|
| ETF | 분배금 재투자 반영 **수정 종가** |
| **261250 합성 금지** | 환율×2로 만들면 일간 리밸런싱과 감쇠가 소실됨 |
| **261240 대체 금지** | 현물 환율로 대체하면 롤오버 효과 누락 |
| 결측 | 미국 휴일은 T-bill 전일 이월 |

### 11.4 기간 및 워밍업

월평균은 **백테스트 이전 데이터로 계산**한다. 별도 워밍업 매매 기간을 두지 않는다.

| N | 필요 데이터 시작 | 매매 시작 |
|---|---|---|
| 1 | 2004-01 | **2005-01** |
| 3 | 2002-01 | **2005-01** |
| 5 | 2000-01 | **2005-01** |
| 7 | 1998-01 | **2005-01** |

**가장 긴 N=7에 맞춰 매매 시작일을 통일한다.** 그래야 네 개 N이 같은 기간을 겪어 비교가 성립한다.

**첫날 상태**: 완성된 범위와 격자 보유, 슬롯 0, 현금 100%. 하향 돌파 조건 덕분에 첫날 대량 체결이 없다.

| 단계 | 대상 | 기간 |
|---|---|---|
| 전략 검증 | 환전 경로 (현물) | 2005~ (데이터에 따라 확장) |
| 상품 검증 | 261240 / 261250 | 2017~ (상장 제약) |

**두 기간이 다르다는 점을 결과 해석에 반드시 반영한다.** ETF 데이터는 2009~2014 대세 하락 구간을 포함하지 못한다.

## 13. 성과 지표

**모든 지표는 §8의 일별 시가평가 총자산 곡선에서 산출한다.**

### 13.1 표준 지표

| 지표 | 주의사항 |
|---|---|
| CAGR | 분모 = 총자산 (단일 기준) |
| MDD | **평가액 기준** (실현손익 기준 금지) |
| Calmar | CAGR ÷ \|MDD\| |
| **Sharpe** | **rf = CD91.** rf=0 금지 |
| Sortino | rf 동일 |
| 총수익률 | — |

**rf = CD91인 이유**: 본 전략은 수익의 대부분이 이자다. rf=0으로 계산하면 "원화 예금만 해도 얻었을 수익"이 전략 성과로 둔갑해 Sharpe가 크게 부풀려진다. **rf를 올바르게 적용하면 Sharpe가 0 근처로 떨어질 수 있으며, 이는 오류가 아니라 정확한 측정이다.**

### 13.2 그리드 전용 지표 (필수)

표준 지표만으로는 그리드의 실패 양상이 드러나지 않는다.

| 지표 | 목적 |
|---|---|
| **최장 보유기간** | 5년 물리는 슬롯이 나오면 전략 재설계 |
| 평균 보유기간 | 회전 속도 |
| 연간 회전 횟수 | 비용 대비 수익의 핵심 변수 |
| 자금 소진율 분포 | "총알 없음" 상태 시간 비중 |
| 평균 투입률 | 자금 유휴 정도 |
| 최대 미실현 손실 | 심리적 감내 한계 |
| **일일 최대 투입 비율** | 다중 체결로 하루에 몇 % 투입되는지 |
| 하루 3개 이상 체결 횟수 | 동일 |
| **격자 이탈 보너스 합계** | 종가 체결 가정의 기여분 (§6.4) |
| 하단 이탈 횟수 / 기간 / 최대 깊이 | 월평균 방식의 대가 (§4.1) |
| 활성 레벨 수 min / max | 범위 축소 위험 |
| 상한 발동 횟수 / 현금 잔류율 | §5.3 작동 빈도 |
| 재조정 시 범위 변화량 | 윈도우 엣지 효과 |

**최장 보유기간이 특히 중요하다.** 연 5%가 나와도 중간에 3년간 −25% 평가손을 안고 있어야 했다면 대부분 그 전에 포기한다. **백테스트는 통과해도 사람이 통과 못 하는 전략**이 그리드에 흔하다.

### 13.3 벤치마크 (필수 병기)

| 벤치마크 | 확인 목적 |
|---|---|
| **B&H + 달러 RP** | 매매의 가치 |
| **분할매수 후 보유** | **익절 로직의 순수 기여** |
| **원화 파킹 100%** | 리스크 대비 정당성 |

> 그리드는 추세장에서 B&H에 구조적으로 진다. 이길 수 있는 유일한 환경은 횡보다.
>
> 질문은 "이기는가"가 아니라 **"얼마나 자주 지고, 질 때 얼마나 지는가"**여야 한다.
>
> 특히 **두 번째 벤치마크와의 비교가 핵심이다.** 여기서 못 이기면 익절 로직을 제거하는 것이 맞다.

## 16. 0단계 — 등가성 검증 (매매 로직 없음)

> **1단계보다 먼저 실행한다.** 매매 로직이 필요 없어 데이터 4종만으로 가능하며, 여기서 "대체 불가" 판정이 나면 그리드 백테스트를 하지 않아도 된다.

### 16.1 가설

```
H₀: 261240 누적수익 ≈ (원달러 현물수익 + 달러금리 − 원화금리) − 총보수
```

### 16.2 측정

| 지표 | 계산 | 합격선 |
|---|---|---|
| 일간수익률 상관 | corr(261240, 이론값) | ≥ 0.97 |
| 베타 | 회귀 기울기 β | 0.98 ~ 1.02 |
| 알파 | 절편 α (연환산) | 총보수 근방 (−0.25% 내외) |
| 추적오차 | 잔차 표준편차 × √250 | ≤ 1.5% |
| **누적 괴리 안정성** | 연도별 (실제 − 이론) | **편차 0.3%p 이내** |

> **마지막 줄이 가장 중요하다.** 상관계수가 0.99여도 연도별 괴리가 들쭉날쭉하면 대체재로 쓸 수 없다. 그리드는 수개월 보유하는데 그 기간에 예측 불가능한 괴리가 붙으면 전략이 아니라 도박이 된다.
>
> **괴리가 크지만 일정하면 괜찮다**(상수 비용 처리 가능). **작지만 불규칙한 것이 훨씬 나쁘다.**

### 16.3 261250 회귀

```
261250_일간수익 = α + β × 261240_일간수익 + ε
```

| 계수 | 의미 | 기대값 |
|---|---|---|
| β | 실효 레버리지 배수 | 1.95 ~ 2.00 |
| **α × 250** | **숨은 비용 연환산 총액** | −0.5 ~ −1.0% |
| R² | 복제 충실도 | ≥ 0.99 |

α가 리밸런싱비용·롤오버·보수차이·감쇠의 합계다. 금리차 캐리는 261240에도 1배로 들어 있어 상쇄되므로 **순수 레버리지 유지비용만 α로 남는다.**

### 16.4 추가 확인

- NAV 대비 프리미엄/디스카운트 크기 (특히 2024~2025 급등 구간)
- LP 호가 의무 공백 시간대 스프레드 확대
- 슬롯 규모 대비 일평균 거래대금 비율 (1% 초과 시 시장충격 우려)

### 16.5 판정

| 판정 | 조건 | 후속 |
|---|---|---|
| **대체 가능** | 전 항목 통과 + 경로 순위가 N·국면에 안정 | 261240을 환전 프록시로 사용 |
| **조건부 가능** | 괴리는 크지만 일정 | 상수 비용 처리 후 사용 |
| **대체 불가** | 괴리 불규칙 또는 β 이탈 | ETF 경로 폐기 |

**261250 별도 조건**: β < 1.95이면 "2배 노출" 전제가 깨지므로 재검토.

### 18.1 주의할 해석 오류

**"이자가 하락을 방어했다"고 읽지 말 것.** RP 금리가 낮아지는 국면은 대체로 달러 약세 국면이다. **금리 하락과 환손실이 함께 오는 구조**이므로 이자의 완충 효과를 기대하기 어렵다.

**신용위험은 0으로 가정했다.** RP는 예금자보호 대상이 아니다. 담보채권이 예탁결제원에 별도 예탁되어 증권사 파산 시에도 담보는 남지만, 백테스트에 반영되지 않은 위험이다.

**기간 편향에 주의할 것.** 원달러 2020~2025는 대세 상승 구간이라 이 구간만 보면 롱 그리드가 무엇을 해도 잘 나온다.
