> **작성일**: 2026-09-22 (KST) · **마지막 업데이트**: 2026-09-23
> **데이터 기간**: SPY **1993-01-29 ~ 2026-08-25** (8,450행) · DIA **1998-01-20 ~ 2026-08-26** (7,195행) ·
> QQQ **1999-03-10 ~ 2026-09-03** (6,915행) · S&P 500 지수 **1927-12-30 ~ 2026-09-18** (24,796행) ·

## 1. 이 검증이 묻는 것

**중간선거 해 9월 마지막 거래일에 사서 다음해 6월 마지막 거래일에 팔면 성적이 좋은가.**
(**진입은 2026-09-22 에 10월 첫 거래일에서 옮겼다** — 결정 ⑫)

Stock Trader's Almanac(Yale·Jeffrey Hirsch)이 **"Sweet Spot"** 이라 부르는 구간이며,
용어와 정의가 그쪽에서 왔다. 웹에서 이 수치를 인용하는 글이 많지만 **전부 같은 원본의
복제라 독립 소스는 하나**다 (§3.1).

**진짜 질문은 하나 더 있다** — 10/1 ~ 6/30 창은 잘 알려진 **「Best Six Months」(11월~4월)를
통째로 품고 있다.** 그래서 「10~6월이라 좋았다」와 「중간선거 뒤라 좋았다」를 가르지 못하면
아무것도 잰 것이 아니다. **그 분리가 이 검증의 축이다.**

## 2. 확정된 설계 결정

### ① 매매 규칙 — 진입·청산 격자를 두지 않는다

> **진입일은 결정 ⑫ 가 9월 마지막 거래일로 바꿨다.** 아래는 「격자를 두지 않는다」는 판단의 기록이며 그 부분은 그대로다.

| | |
| --- | --- |
| **확정** | 진입은 **10월 첫 거래일 종가**, 청산은 **다음해 6월 마지막 거래일 종가**. 진입·청산 격자를 두지 않는다 |
| **탈락안** | 진입 3종(9/1 · 10/1 · 선거일 다음 거래일) × 청산 4종(12/31 · 3/31 · 6/30 · 9/30)의 작은 격자 |
| **근거** | 사용자가 「사용자 규칙 한 칸만」으로 정했다 (2026-09-22). 표본이 칸당 6~24건뿐이라 12칸으로 벌리면 **한 건이 칸을 뒤집는다** — 격자의 값이 아니라 잡음을 보게 된다. 대신 **날짜에 실체가 있는지는 축(사이클 위치)이 답한다** |

### ② 휴장 처리 — 기존 진입 함수를 쓸 수 없다

> 목표일이 달라 달력일 인자 하나로 겨눌 수 없다.

| | |
| --- | --- |
| **확정** | 10월 1일이 휴장이면 **그 이후 첫 거래일**, 6월 30일이 휴장이면 **그 이전 마지막 거래일** |
| **탈락안** | `measure/calendar_entry.month_entry_dates` 를 `calendar_day=1` 로 재사용 |
| **근거** | 🔴 **그 함수는 앞당김이라 방향이 반대다** (`calendar_entry.py:243` — 「목표일 이하인 거래일 중 가장 늦은 것」). `calendar_day=1` 로 부르면 **10월 1일이 휴장인 해가 전부 「진입일 없음」으로 빠진다** — 주말만 따져도 7년에 2년꼴이고, 실측 대상에서 1994·2006·2022·2023 넷이 여기 해당한다. 앞당기면 9월로 넘어가 **4분기 밖에서 사게 된다** |

| **탈락안** | 기존 기준선 셋(단순 보유 · 200일선 아래 조건부 · 무작위 진입)만 쓴다 |

### ⑩ 기준선의 청산 규칙을 신호와 같게 둔다

> **결정 ⑫ 로 진입이 「아무 달 «마지막» 거래일」이 되고 `EXIT_MONTH_OFFSET` 이 9 가 됐다.**
> **「청산 규칙을 신호와 공유한다」는 판단 자체는 그대로다** — 값만 따라 움직인다.

| | |
| --- | --- |
| **확정** | 기준선은 「**아무 달** 첫 거래일 진입 → **진입 달 + 8개월**의 마지막 거래일 청산」 |
| **탈락안** | 전 거래일 진입 → 고정 거래일 구간(188일) 보유 |
| **근거** | 고정 거래일로 두면 **보유 길이가 신호와 어긋나고** 그 차이가 그대로 기준선 대비 차이에 실린다. 청산 규칙을 공유하면 진입만 갈리므로 **「그 해가 원래 그런가, 10월 진입이 특별한가」**에 바로 답한다. `EXIT_MONTH_OFFSET = 8` 한 값이 신호와 기준선을 잇는다 |

### ⑪ 끝이 잘린 달을 양쪽에서 뺀다

> **결정 ⑫ 로 진입에서 빼는 달이 «첫 달»에서 «마지막 달»로 뒤집혔다.** 진입이 그 달의
> 마지막 거래일이므로, 달 중간부터 시작한 데이터라도 그 달의 마지막 거래일은 진짜다.
> **「끝이 잘린 달을 쓰지 않는다」는 판단 자체는 그대로다.**

| | |
| --- | --- |
| **확정** | 진입에서 **데이터의 첫 달**, 청산에서 **데이터의 마지막 달**을 쓰지 않는다 |
| **근거** | 첫 달은 데이터가 중간부터 시작했을 수 있어 **「첫 거래일」이 진짜 첫 거래일이 아니다.** 마지막 달은 끝났는지 알 수 없어 **「데이터가 끊긴 날」이 월말로 잡히면 보유가 짧은 가짜 표본**이 된다. `month_entry_dates` 가 마지막 달을 빼는 것과 같은 논리를 양 끝에 건다 |

### ⑫ 진입은 «9월 마지막 거래일» 종가 — 보유를 달력 분기에 맞춘다

| | |
| --- | --- |
| **확정** | 진입 **9월 마지막 거래일 종가**, 청산 **다음해 6월 마지막 거래일 종가**. 개월 수 **9** |
| **탈락안** | 10월 첫 거래일 진입 (개월 수 8) |
| **근거** | **보유가 4분기·1분기·2분기에 정확히 맞아떨어져** 분기 분해가 성립한다(결정 ⑮·⑯). 실측으로 **24개 중간선거해 전부에서 9월 마지막 거래일이 10월 첫 거래일의 바로 앞 거래일**이라(간격 1거래일, 예외 0) 격자 탐색이 아니라 **하루 이동**이다. 사용자 결정 (2026-09-22) |

🔴 **부수 효과로 휴장 처리의 방향이 하나가 된다.** 진입과 청산이 둘 다 「그 달 마지막 거래일」
(**앞당김**)이라 결정 ② 의 「방향이 반대」가 사라진다. 대신 **끝이 잘린 달을 빼는 쪽이 뒤집힌다** —
진입에서 빼야 하는 것이 데이터의 **첫** 달이 아니라 **마지막** 달이다(결정 ⑪ 과 대칭).
그 달의 「마지막 거래일」은 실제 월말이 아니라 **데이터가 끊긴 날**이고, 놓치면 보유가 짧은
가짜 표본이 생기면서 **예외는 나지 않는다.**

🔴 **대가를 명시한다.** 결정 ④ 가 세운 **「10~6월이라 좋았나, 중간선거 뒤라 좋았나」의 분리가
산출물에서 사라진다.** 그 답(기준선 대비 차이가 중간선거해만 +8.5 ~ +17.8%p, 나머지 열두 칸은
0 근처)은 **10월 진입·네 칸으로 잰 기록**이며 `결과.md` 가 그 시점의 측정으로 갖는다 —
지금 구성으로는 재현되지 않는다.

**기준선 컬럼은 그대로 남는다.** 기준선이 「중간선거해에 **아무 달** 마지막 거래일 진입 →
9개월 뒤 달 마지막 거래일 청산」이라 **12달 전부를 계속 계산하며**, 「그 해가 원래 그런가,
9월 말 진입이 특별한가」에는 계속 답한다. **사라지는 것은 「다른 세 해와 견주기」뿐이다.**

> **`.claude/rules/trading.md` 는 「확정 칸으로 좁히는 것을 «검증 등급»에는 적용하지 않는다」로
> 적혀 있다.** 이 결정이 그 문장의 예외이며, 규칙 문서를 고칠지는 사용자가 정한다.

### ⑭ `사이클 위치` 컬럼은 전 행이 같은 값이어도 남긴다

| | |
| --- | --- |
| **확정** | 축이 하나여도 컬럼을 낸다 |
| **탈락안** | 값이 하나뿐이니 컬럼을 없앤다 |
| **근거** | **`손절선(%)` 을 전 행이 같아도 남기는 것과 같은 이유다** (`src/verify_lab/CLAUDE.md` 「매매 산출물 계약」) — 없으면 **산출물만 봐서 무엇을 잰 표인지 판별되지 않는다.** 축을 넓혀 돌린 실행과 좁힌 실행이 같은 자리를 덮으므로 더욱 그렇다 |

### ⑮ 분기 분해는 «무손절» 기준으로만 낸다

| | |
| --- | --- |
| **확정** | 분기별 수익과 분기별 낙폭을 **무손절 경로 하나**로만 낸다. `분기.csv`·`분기내역.csv` 에 `손절선(%)` 축이 없다 |
| **탈락안** | 손절선 격자마다 분기 표를 낸다 |
| **근거** | **손절이 걸리면 보유가 중간에 끊겨 분기가 온전하지 않다** — 남은 분기는 표본이 사라지고, 끊긴 분기는 「그 분기 성적」이 아니라 「손절까지의 성적」이 된다. 이 분해가 묻는 것이 **「어느 분기가 수익을 만들고 어느 분기에 밀리나」**라 끝까지 들고 간 경로를 봐야 한다. 손절선이 아직 미정인 것과도 맞는다 |

### ⑯ 분기별 낙폭은 «두 분모»로 낸다

| | |
| --- | --- |
| **확정** | `진입가 대비 최악(%)` 과 `분기 시작가 대비 최악(%)` 을 **둘 다** 낸다 |
| **탈락안** | 하나만 낸다 |
| **근거** | **다른 질문이고 각각 다른 검산을 갖는다.** 진입가 대비는 **세 분기의 최솟값이 전체 보유 중 최악과 같아야** 하고, 분기 시작가 대비는 **같은 행의 분기 수익률과 분모가 같아** 나란히 읽힌다. 하나를 고르면 그 선택이 결론에 숨는다 (측정의 원칙 1) |

**산식을 새로 만들지 않는다.** 분기 하나를 `execution/trade_fill.simulate_scheduled_trade` 에
**무손절로** 넘기면 `분기 수익률` 과 `분기 시작가 대비 최악` 이 그대로 나오고,
`진입가 대비 최악` 은 거기서 **분모만 바꾼 항등식**으로 얻는다 —

```
부호            = 아래로 걸면 −1, 위로 걸면 +1
최악의 가격      = 분기 시작가 × (1 + 부호 × 분기 시작가 대비 최악)
진입가 대비 최악 = (최악의 가격 ÷ 진입가 − 1) × 부호
```

🔴 **부호를 빼면 「아래」 칸에서 틀린다.** 체결식이 내는 값에는 거는 방향이 이미 반영돼 있어
가격을 되돌릴 때도 같은 부호를 태워야 한다 — **「위」 한 방향만 볼 때는 부호가 1 이라
눈에 띄지 않는다.** 두 번째 판정식을 만들면 같은 값이 두 곳에서 갈라진다 (절대 원칙 5).

**분기 구간은 달력 분기로 가른다** — 보유 구간(진입 다음 거래일 ~ 청산일)을 달력 분기로 묶고
각 묶음의 마지막 거래일을 경계로 쓴다. 달을 세어 자르지 않는 것은 **규칙이 바뀌어도 따라오게**
하기 위해서이고, 묶음이 셋이 아니면 내부 불변조건 위반으로 즉시 실패한다.

### ⑰ 진입 위치 지표 — RSI 는 Wilder, 이격도는 공통 SMA, 52주는 252거래일

| | |
| --- | --- |
| **확정** | 진입일 종가까지로 **52주(252거래일) 최고 종가 대비 거리 · 200일 이격도 · 20일 이격도 · Wilder RSI(14)** 를 내고 그 해의 결과와 한 행에 싣는다(`진입위치.csv`). **SMA 는 `measure.baseline.simple_moving_average` 하나가 낸다** — 조건부 기준선의 판정 마스크도 그 함수를 쓰게 바꿨다 |
| **탈락안** | ① Cutler RSI(평균을 SMA 로 낸다) ② 이격도를 이 매매법 안에서 따로 계산 |
| **근거** | ① **Wilder 평활은 지수형 평균이라 측정의 원칙 15(SMA 만)와 문자 그대로는 부딪힌다.** 그 원칙의 취지는 「둘을 나란히 내어 고를 여지를 만들지 않는 것」이라 한 방식만 쓰면 충족되고, **증권앱·차트가 보여 주는 값이 Wilder 라** 사용자가 대조할 수 있다(원칙 8·14). 사용자 결정 (2026-09-23). ② SMA 는 원칙 15 가 모든 매매법에 요구하는 산식이라 두 벌이면 조용히 갈라진다(절대 원칙 5). 공통화한 뒤 역방향을 재실행해 **산출물 diff 0** 을 확인했다 |

**창이 차기 전은 비운다** — DIA 1998(상장 1998-01-20)의 52주·200일 칸이 그렇다. 0 으로 채우면
「그때 고점이었다」가 된다. RSI · 52주 최고는 측정의 원칙에 없어 이 매매법에 둔다.

### ⑱ 분할매수 격자 — 결과를 보기 전에 고정한다

| | |
| --- | --- |
| **확정** | 대상마다 10칸 — 일시매수(대조) · **A** 9·10·11·12월 말 4등분 · **B** 첫 몫 대비 사다리 3등분(간격 5% · 10%) · **C1** RSI(14) 30 아래 3등분 · **C2** 20일 이격도 95% 아래 3등분. | **탈락안** | ① 결과를 본 뒤 간격·기준값을 조정 ② ETF 만 장중 지정가 체결 ③ 분할 횟수를 축으로 더하기 ④ 200일선 아래를 C2 기준으로 ⑤ 추가 매수 창을 1분기까지 ⑥ 손절과 함께 격자로 ⑦ **B·C 를 판정일 종가에 체결 — 처음 안이었다** |
| **근거** | ① 사용자 지시 — **2018년에 맞춘 값을 고르지 않는다**(2026-09-23). 값은 계획서 승인 시점에 고정했다 ② 지수는 종가뿐이라 ETF 와 지수가 다른 규칙이 된다 ③ 칸이 곱으로 늘면 한 해가 순위를 정한다 ④ 200일선은 4분기 안에 거의 깨지지 않아 사실상 2018 전용 칸이 된다 ⑤ 최저점이 ETF 21건 전부 4분기에 있었다(`결과.md` §9.2) — **이 창 자체가 결과를 보고 정한 값**이라는 사실을 결과 문서 한계에 적었다 ⑥ 사용자가 분할매수부터 정하기로 했다 ⑦ **종가가 찍혀야 알 수 있는 조건으로 그 종가에 사는 것이라 같은 봉 안의 미래 참조**다 (패키지 절대 원칙 1 「판정일 종가로 판정하고 집행은 다음 거래일」). 미국장 마감이 한국 시각 새벽이라 실제 집행도 다음 거래일이다. 코드 리뷰가 짚어 사용자가 바꿨다(2026-09-23). **다음 거래일 «시가»는 탈락** — 지수에는 시가가 없다. 바꾼 뒤에도 결론은 같았다(`결과.md` §17) |

**판정은 12월 마지막 거래일 «전날»까지다** — 체결이 다음 거래일이라 그래야 창 안에서 끝나고, 12월 말 일괄 매수와 같은 날 겹칠 때 순서가 분명하다. **조건부 방식은 「새로 들어간 날」(전날 거짓 → 그날 참)에만 판정한다** — 조건이 이어지는 날마다 사면
과매도 구간 첫 며칠에 몫을 다 써서 사실상 한 날에 몰아 사는 것이 된다. **체결일 당일 장중은 새 몫의
낙폭에 넣지 않는다** — 종가에 샀으므로 그날 장중은 들고 있지 않았다.

**새 산식은 배정액 기준 보유 중 최악 하나다.** 몫마다의 수익률은 `simulate_scheduled_trade` 를
무손절로 불러 얻고, **일시매수 칸에서 기존 체결의 수익률·보유 중 최악과 정확히 같다**는 동치를
테스트가 묶는다.

### ⑲ 분할매수 집계는 «분기 표 형태»로 — 시기 행을 내지 않는다

| | |
| --- | --- |
| **확정** | `분할매수.csv` 는 대상 × 칸마다 한 행이다 — 표본 · 합계 · 평균 · 중앙값 · 오른 비율 · 최고 · 최악 · 일시매수 대비 차이 · 보유 중 최악의 분포 · 평균 투자 비율 · 첫 몫 대비 평균 매수가 · 추가 몫이 규칙으로 체결된 진입 수(몫 수가 아니고, 12월 말 일괄로 산 것은 세지 않는다). 원자료는 `분할매수내역.csv` 가 진입마다 몫별 체결일·체결가·사유로 담는다 |
| **탈락안** | `execution/periods.period_rows` 로 시기 5행을 내고 분할 고유 컬럼을 붙인다 — **계획서의 처음 안이었다** |
| **근거** | `period_rows` 는 시기 구간 마스크를 안에서만 만들어 **분할 고유 컬럼(중앙값 · 투자 비율 · 평균 매수가)을 구간마다 붙일 자리가 없다.** 밖에서 마스크를 다시 만들면 시기 분할이 두 벌이 되고(절대 원칙 5), 고유 컬럼을 `전체` 행에만 채우면 나머지 네 행의 빈칸이 「잴 수 없었다」로 읽힌다. **같은 패키지의 `분기.csv` 가 이미 이 형태**라 그 관용을 따랐다. 대가: 분할 표에 시기 행이 없다 — ETF 는 어차피 전 구간 표본 미달이고, 일시매수의 시기 5행은 `성적표.csv` 에 남는다. **요약 컬럼(합계 · 평균 · 중앙값 …)은 분기 표와 같은 함수 하나가 낸다** |

**몫이 없는 칸은 비우고 몫이 있는데 안 산 칸은 사유에 「미체결」을 적는다** — 둘을 한 값으로 적으면
「그 방식에는 그 몫이 없다」와 「조건이 안 왔다」가 구별되지 않는다.

🔴 **고장 방식이 반대다.** 국내는 **0** 이라 `validate_market_data` 의 「0 이하 가격」에 걸려
**예외로 즉시 드러나고**, 미국은 **종가로 채워져** 있어 **검증을 그대로 통과한다.**
미국 쪽이 더 나쁘며 그것이 결정 ⑥ 의 근거다.

> **다시 재지 않아도 되게** 남긴다 — 코스닥 종합만 전 구간 OHLCV 를 쓸 수 있다.

### 3.7 「최근 N년」 구간은 표본이 1~2건이다

시기 5행 중 **최근 10년은 2건, 최근 5년은 1건**이다 — 신호가 4년에 한 번이라 구조적이다.
`판정가능` 이 그 사실을 표에 남기며, **원칙 17 에 따라 행은 지우지 않는다.**
S&P 500 지수만 앞/뒤 절반(12/12건)이 하한을 넘어 **「식고 있는가」를 실제로 볼 수 있는
유일한 대상**이다.
