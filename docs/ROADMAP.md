# ROADMAP

> 이 문서는 **검증 대상 목록과 진행 상태의 SoT**입니다.
> 무엇을 검증했고, 무엇이 남았고, 각 검증이 어떤 상태인지는 여기서만 관리합니다.
>
> 이 프로젝트가 왜 시작됐는지는 [context/README.md](context/README.md)를 참고하세요.
> 출발점은 "운용 중인 포트폴리오의 낮은 QQQ 상관이 타이밍 신호에서 나왔다"는 분해 결과이며,
> 검증 결과를 해석할 때 **"QQQ와 다르게 움직이는가"** 를 함께 봅니다.

### 2번 이후 검증에서 미리 알아둘 것

- **비트코인 4년 주기설은 "특정 하루"가 아니라 "반감기 후 N개월 구간"** 이라, 지금의 이벤트-일 기반 틀에
  그대로 맞지 않을 수 있습니다. 착수 시점에 `measure/` 확장이 필요한지 먼저 판단합니다.
- **탑티어 우량주 검증은 개별종목**이라 생존편향(상장폐지·피인수 종목 제외로 성과가 부풀려지는 현상)을
  다뤄야 합니다. 지수 검증에는 없던 문제입니다.
- 국내 개별종목을 다룰 때는 **2015년 6월 가격제한폭 15%→30% 확대**가 일간 극단치의 물리적 상한을 바꿉니다.
  지수 ETF에는 사실상 영향이 없지만 개별종목에는 있습니다.

#### 실측 기록 — `.claude/rules/` 자동 로드 (2026-08-09)

**결과: `paths:` frontmatter 자동 로드는 동작한다. 트리거는 편집이 아니라 `Read`다.**

두 패턴을 각각 실측했다.

| 패턴 | 읽은 파일 | 주입된 것 | 확인에 쓴 질문 |
| --- | --- | --- | --- |
| `**/*.py` | `src/verify_lab/utils/logger.py` | `.claude/rules/python.md` 본문 + `src/verify_lab/CLAUDE.md` 본문 | 반올림 규칙 (백분율 2자리 / 비율 4자리) |
| `docs/**` | `docs/ROADMAP.md` | `.claude/rules/docs.md` 본문 | 스펙과 결과의 분리 (설계 변경 → `spec/`, 데이터 갱신 재실행 → `research/`) |

두 질문 모두 **해당 규칙 문서에만 있고 다른 문서에는 없는 값**을 골랐다.
다른 문서에는 "python.md를 따른다" 같은 포인터만 있고 값이 없다.

| 확인된 것 | 내용 |
| --- | --- |
| 트리거 | 해당 경로 파일의 **Read**. 편집까지 갈 필요 없음 |
| 함께 주입되는 것 | 경로에 걸린 `.claude/rules/*.md` + 해당 디렉터리 계층의 `CLAUDE.md` |
| **남은 구멍** | **기존 파일을 열지 않고 새 파일부터 만드는 경우** 규칙이 주입되지 않는다. 이때는 직접 읽어야 한다. `data/`·`measure/`·`report/`·`studies/`가 비어 있어 초기 작업 대부분이 여기 해당한다 |

> **검증 방법에 대한 메모**: 모델에게 "규칙이 로드됐냐"고 그냥 물으면 안 된다.
> `CLAUDE.md`에 적힌 "자동 로드된다"는 문장을 근거로 추측해 답하기 때문이다.
> 실제로 그런 오답이 한 번 나왔다. **해당 규칙 문서에만 있는 구체적 값**을 묻고,
> "파일을 추가로 열지 말고 추측하지 말라"는 제약을 함께 걸어야 한다.

> 유틸 4종(`logger`·`formatting`·`cli_helpers`·`meta_manager`)은 이전 프로젝트에서 복사만 된 상태입니다.
> 내부에 옛 패키지명 참조가 남아 있고 `common_constants.py`가 아직 없어 그대로는 동작하지 않습니다.
